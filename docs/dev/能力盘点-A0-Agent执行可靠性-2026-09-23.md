## 2. 结论：各切片真正的新增范围（去掉与已有重叠的部分）

- **A-1（交付证据核验）**：只加「宿主只读验证器 + 两个并列字段（模型报告 / 宿主核验）」。
  phase 语义、脏值清洗、推送通道全部沿用 #1/#4/#15；结构化来源等 U-3b。
  **不新建存储**（证据仍落在既有 goal 文档里）。
- **A-2（目标级预算与停止理由）**：只加「可选 token/时间预算 + 耗尽先停新轮 + 可恢复」。
  用量口径直接吃 #9（H-6b 的 logicalTurnId/runId）；次数上限 #5 继续独立存在，
  两者不互相替代；**不合并** #7 的上下文预算（一个是「压缩前后」的，一个是「目标花多少」的）。
- **A-3（可恢复执行与动作回执）**：只加「四态回执 #12 + 不可确认副作用的展示与用户选择」。
  事务 ID、幂等记录、快照全部复用 #11/#10；**F7 先落「启动回执」**，A-3 跟随。

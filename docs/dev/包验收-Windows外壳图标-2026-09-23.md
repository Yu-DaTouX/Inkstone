日期：2026-09-23 ｜ 归属：H-8c 的「Windows 外壳图标仍按包验收单列」 ｜ **本单不触发打包**

## 为什么只做静态核验

外壳图标（任务栏、开始菜单、安装器、卸载器、安装目录）**装完才看得见**。
规范明确：暂无发布计划时不为了这片自动重打全部安装包。所以这里把**能静态确认的**先钉住，
把**必须装完才能看的**逐项列成待验清单 —— 不拿静态检查冒充包验收。

静态命令：`node scripts/check-shell-icons.mjs`（已进 `npm run check`）

## 1. 静态核验结果（本次已跑）

| 项 | 结果 |
|---|---|
| `build/icon.ico` | 含 **16 / 32 / 48 / 64 / 128 / 256**，无坏条目 |
| `build/icon.png` | **512×512**，位深 8，colorType 6（带透明通道） |
| `build/installerSidebar.bmp` | **164×314**（NSIS `MUI_WELCOMEFINISHPAGE_BITMAP` 约束） |
| electron-builder 图标指向 | 走 `build/` 约定路径，没有被显式覆盖到别处 |
| `nsis` 快捷方式 | `createDesktopShortcut` / `createStartMenuShortcut` = true，`shortcutName: 砚` |

判据依据：Windows 任务栏与列表要 16×16、开始菜单 32×32、桌面 48×48、高 DPI 大图标 256×256；
PNG 必须是透明通道，否则圆角/异形图标会被系统填成黑底（这是最常见的“装完才发现”的问题）。

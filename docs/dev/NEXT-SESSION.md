# 新会话入口

**接下来做什么**看 [实施计划](../plan/README.md)（活动主题文档均按「一次会话一片」切分）；
**现在是什么样**看 [HANDOFF.md](HANDOFF.md)；文档分工见[文档索引](../README.md)。

可复制以下内容给新会话：

~~~text
阅读 AGENTS.md 和 docs/plan/README.md，检查 git status --short，保留已有修改，然后继续用户指定的工作。
先读 docs/dev/HANDOFF.md 了解当前状态与验证基线；按 docs/PROJECT.md 定位实现；
按工程 ID 查 docs/dev/ENGINEERING-CHECKLIST-2026-09-15.md 的验收条件。
测试约定只看 docs/dev/TESTING.md。未完成项的切片与出口只更新 docs/plan/；
完成度与证据只更新 HANDOFF，六栏齐备才算完成，不把历史报告或旧包当成本次通过结果。
~~~

## 维护

- 未完成项只在 `docs/plan/` 里改；状态与证据只在 HANDOFF 里改。
- `docs/archive/` 的文件**不再更新**（已结束或已被取代）。

## 写记录的规矩

- 只写**可核对的事实**：改了哪些文件、用什么命令验证、结论是什么。
- 测试数量、版本号、价格、临时路径不作为长期事实（会被后续实现推翻）。
- 「已知未闭环」的问题在解决后回到原记录补一行状态，并链接到新的修复记录；
  历史记录不重写结论，只追加「后续」说明。
- 记录里的截图/产物放 `assets/`，文件名带日期前缀。

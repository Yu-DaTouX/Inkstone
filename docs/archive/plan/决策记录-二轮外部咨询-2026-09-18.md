## 2. 逐题结论

### 2.1 「丢弃工作区改动」的折中：否

**GPT**：patch 备份能把「绝对不可恢复」降为「有恢复路径」，但**不能变成真正可逆**；
「备份成功」与「可恢复」不是一回事，而确认文案容易制造「已保险」的错觉，**反而提高误操作概率**。

**落地**：折中被否，默认不做的结论不变。**换掉了论据**（见 §3），
真正站不住的是三类：普通 `git diff` **不含未跟踪文件**、`core.autocrlf` 的换行转换、
`submodule`（gitlink）—— 都可能让补丁应用不回去。

**落进** [实施-07 §4](实施-07-Git与环境菜单收尾-已完成.md)。

### 2.2 「每个项目最后一个会话」：加元数据，不新增真源

**GPT**：优先「强制落盘 + 扫描推导」，**不另设真源** —— 会话文件是唯一真源，
`lastSessionId` 会产生**双写一致性问题**。但仅靠 `mtime` 不够稳（复制、恢复、时钟变化都会污染排序），
应使用会话内单调序号或显式 `lastOpenedAt`，**仍由会话文件自身承载**。

**落地**：把 [实施-09](../../plan/active/实施-09-交付与验收收尾.md)-S3 从「唯一的**新功能**尾巴（1 天）」
降级为「补 `lastOpenedAt` 元数据 + 扫描推导（0.5 天）」，并写明**不依赖 `mtime`**。

### 2.3 薄层准入：不问「有没有 CLI」，问「语义契约是否等价」

**GPT**：只有官方路径**同时**满足 5 条才算等价 ——
① 调用时机等价 ② 输入 / 输出结构等价 ③ 失败 / 取消语义等价 ④ 延迟预算可接受 ⑤ 宿主可观测并正确渲染。
任一关键契约缺失即判「不等价」；**若补齐必须注册模型工具，结论是「当前架构做不到」，不是塞进薄层**。

**落地**：替换 [实施-01 §1](../../plan/active/实施-01-默认pi架构迁移.md) 原来那句含糊的「宿主无法通过 CLI / RPC 表达」，
改成 5 条可逐条打勾的契约表 + **三个判定出口**（全过→宿主服务/CLI；缺契约但不需注册工具→薄层；
缺契约且必须注册工具→判做不到）。最后一条尤其重要：它同时堵住了「拿薄层当万能借口」。

### 2.4 钩子缺失时的止损：救 3 项、弃 2 项

**GPT**：只近似保住 ①③④，②⑤缺口大时直接标未满足。

- **近似保住**：① 回合边界预算守卫（非请求前拦截）；③ 宿主触发压缩（失去原子接管）；
  ④ 独立状态归纳（可能滞后一到两轮）。
- **直接标未满足**：② `<TASK_STATE>` 位置保证（没有请求前重写就**无法**在任意位置插入）；
  ⑤ `recall`（模型没有**可调用回读入口**，宿主代劳只是把内容塞进上下文，**不是 recall**）。
- **风险**：别把「近似」包装成同等语义。

**落地**：[实施-06 §3](../../plan/active/实施-06-上下文管理收尾.md) 新增**分支 B 止损表**，
并加一条**口径纪律**：近似做法在其它文档里不得被简称成原能力名
（「回合边界预算守卫」不得写成「请求前硬预算」）。

### 2.5 1 天可行性验证：必须含端到端最小闭环

**GPT**：单点验证只能证明组件各自存在，**不能证明协议、权限、进程边界、工具结果回填、
后续推理能不能串起来**。最小闭环应覆盖「模型 → 本机 CLI → 结构化结果 → 模型继续一轮」，
其余项目做单点验证。**风险**：闭环范围必须极小，否则 PoC 会膨胀成半实现、反而掩盖验证目标。

**落地**：[实施-01 S1](../../plan/active/实施-01-默认pi架构迁移.md) 在原有 7 项单点观测之外，
新增**必测项「端到端最小闭环」**，并写明「闭环不通过，S1 的出口不算完成」——
因为 02–06 全都建立在「串得起来」这个前提上。

## 3. 本轮核查出的一处不准确（不要写进文档）

GPT 在 §2.1 里把「二进制」列为 patch 无法表达的对象 —— **这条不准确**：
`git diff --binary` 能生成**可应用**的二进制补丁。

它在同一条里给的另外几项（未跟踪文件、权限 / 换行、submodule）里，
**权限位**基本能被 git 记录（`100644` ↔ `100755`），也不该照抄；
真正站得住的是 **untracked / `core.autocrlf` / `submodule`** 三类。

**纪律**：这类「听起来合理但经不起核对」的细节，进文档前必须核实；
本次落笔时已**换成站得住的论据**，并把 GPT 原文的错误版本留在本节备查。

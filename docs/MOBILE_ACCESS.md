# 用 Android 手机接入砚

手机可以查看电脑上的会话和运行状态、回答普通问题、发消息、把语音转成文字，以及查看电脑提供的成果。任务仍在 Windows 电脑上执行。电脑休眠、关机或退出砚后，手机暂时无法连接。

目前手机应用仍在本机测试，尚无公开 Android 发行包。此页记录已实现的连接流程，实际可用入口以安装的桌面与手机版本为准。

## 1. 让两台设备互相可达

推荐在电脑和手机上登录同一个 Tailscale 网络：

- [下载 Windows 版 Tailscale](https://tailscale.com/download/windows)
- [下载 Android 版 Tailscale](https://tailscale.com/download/android)
- [Tailscale Android 安装说明](https://tailscale.com/docs/install/android)

砚只提供连接入口，不会替你安装或登录 Tailscale。登录后，确认两台设备在 Tailscale 中都在线。也可以使用同一局域网；已有 SSH 通路的用户可以自行配置端口转发。

## 2. 在电脑上开启手机接入

在**包含手机接入功能的桌面版本**里，打开 **设置 → 手机接入**：

1. 保持监听方式为 **Tailscale**，开启「允许手机接入」。页面的「正在监听」后面会显示电脑地址，例如 `100.101.102.103:37892`。这就是手机要填的电脑地址。
2. 点击「生成配对码」。页面显示 6 位配对码、有效时间和二维码。配对码 5 分钟有效、只能使用一次；输错 5 次后会失效。
3. 手机相机若能打开二维码中的砚链接，可直接将地址和配对码填进手机应用；确认内容后再点「连接电脑」。也可以在手机应用中手动填写。扫码只预填内容，不会自动批准连接。

二维码里包含临时配对码。不要把截图发给其他人；过期或取消后重新生成即可。

若页面显示没有 Tailscale 地址，请先确认 Windows 版 Tailscale 已连接。选择「仅本机」时显示的 `127.0.0.1` 不能由手机直接访问，需自行建立 SSH 端口转发。选择指定局域网地址时，手机应在可访问该地址的网络中。

## 3. 在 Android 应用里连接

打开砚手机端，扫描电脑上的二维码，或输入「电脑地址」「6 位配对码」「此手机名称」。配对完成后，首页显示电脑上的会话和待回答问题；进入会话可阅读历史、发消息和查看成果。

工作台从上到下显示待回答问题、活动会话、项目文件夹和最近会话。最近会话附带最后一条已读取的消息摘要，点项目进入该目录的会话列表。底部可搜索会话、目录名和已读取的摘要，右上角进入设置。运行中、待回答与电脑当前打开分别显示，手机打开某个历史会话不会把它标成正在运行。

底部新建按钮使用电脑当前设置的工作目录，并切换电脑当前会话；操作前会说明这一点。它目前不能直接在手机所选的项目目录下新建。

展开屏或较宽的应用窗口会并排显示项目列表和详情。详情顶部的侧栏按钮可收起列表，让内容使用可用宽度，再点一次展开；当前会话和草稿保留。折叠或缩窄窗口后继续显示已选会话，键盘打开时输入栏保持在键盘上方。这是会话归类，目前还不是项目文件浏览器。应用读取系统的铰链范围避让内容；Samsung Fold6 的内外屏已有实机检查，遮挡铰链和桌面姿态仍待对应状态验证。

会话输入框保留砚的终端式提示和等宽文字，语音按钮只把识别文字填入输入框。工具调用按轮次折叠，点开查看工具名称与失败数量。正在执行时，输入区上方显示状态和停止入口。细加载条表示读取或重连中的不确定进度；界面切换使用轻微淡入，并遵循系统减少动画的设置。

长会话先显示最近 60 条，向上点击「更早消息」继续读取。切回近期会话时先显示内存缓存，再同步电脑的新内容；缓存不会写入手机存储，退出应用即清空。新版桌面支持按消息分页；仍运行旧桌面时，手机最多读取最近 500 条，更早记录会提示在电脑查看。

## 待回答提醒

在工作台点击提醒入口，或进入 **设置 → 待回答提醒** 开启手机通知。Android 13 及以上版本需要系统通知权限。允许后，手机显示一条安静的常驻通知：运行时显示当前任务标题和「正在运行」，需要回答时显示「等待你回答」，空闲显示「已连接」，断线显示「重新连接中」。锁屏公共版本隐藏任务标题。

电脑出现新的待回答问题时，另发一条提醒。多个问题合并显示数量，同一个未处理的问题不会反复响铃；点通知打开手机端查看和回答，问题处理完后提醒消失。锁屏通知不包含问题正文或项目内容。若拒绝权限，可在手机设置中打开系统通知设置。

后台提醒依赖手机仍能通过 Tailscale 连接正在运行的砚。电脑休眠、网络断开、系统或厂商省电策略结束后台服务时无法保证即时送达；重新打开手机端会拉取尚未处理的问题。敏感确认在手机上只能拒绝，同意仍需在电脑上操作。

电脑的 **设置 → 手机接入** 可撤销已配对手机。设备令牌存在手机的系统安全存储中。

## 语音输入

点击输入栏的波形图标开始语音输入。首次使用需要麦克风权限；录音时，小波形随实际收音变化，方形按钮结束录音并转写，取消按钮或返回键放弃录音。录音、转写状态都显示在原输入栏内，切到后台会取消录音。结果只填入输入框，需要核对后点击发送。

识别由手机已安装的服务提供，服务可能联网，离线识别不保证可用。Samsung Fold6 已验证服务启动、波形与取消，真实语句的识别准确率仍需实际使用确认。

如果出现「系统无识别服务」，请检查手机的语音输入或语音助手设置，安装或启用可用的识别服务，也可使用键盘上的麦克风。如果提示识别服务缺少麦克风权限，需要在系统设置里给**该识别服务**授权；砚自身的麦克风权限不能代替它。当前小米测试设备的第三方识别服务处于这一状态。不同型号和系统版本菜单可能不同，不能假定某个厂商服务一定可用。

## 排查连接问题

| 现象 | 检查 |
| --- | --- |
| 电脑上没有地址 | 先连接 Tailscale，再重新打开手机接入；确认砚仍在运行。 |
| 手机连不上电脑 | 检查两台设备的 Tailscale 在线状态、电脑地址与端口；从局域网连接时确认网络可达。 |
| 配对码无效 | 在电脑上重新生成，使用新码；不要重复使用已成功配对的码。 |
| 手机看不到新进展 | 下拉刷新；检查电脑是否仍在运行、手机是否联网。 |

手机端 APK 的本机调试签名构建与正式发行版应分开对待。旧 Windows 安装包可能尚无「手机接入」入口；请以实际安装版本为准。

# 开始使用 Inkstone

[返回主页](../README.md) · [English](GETTING_STARTED_EN.md)

## 安装与启动

从 [GitHub Releases](https://github.com/Yu-DaTouX/Inkstone/releases) 选择 Windows 发行包。下载前阅读该版本的发布说明；开发分支中的界面或功能可能尚未包含在发行包中。

| 版本 | 启动方式 | 适合的使用方式 |
| --- | --- | --- |
| 安装版 | 运行 `*-setup.exe` 并按安装向导操作 | 在常用电脑上使用 |
| ZIP 版 | 解压 `*-portable-fast.zip` 后运行 `砚.exe` | 解压后直接使用，无需安装 |
| 单文件便携版 | 运行 `*-portable.exe` | 携带应用及其旁边的数据目录 |

发行包已经包含 pi 运行时，无需安装 Node.js 或 pi。模型服务需要另外配置，额度和费用由所选服务决定。目前发行包未提供代码签名，请从本仓库发布页获取，并核对该版本提供的 `SHA256SUMS.txt`。

## 接入模型

1. 启动应用，打开 **设置 → 模型**。
2. 选择服务，在软件内登录或配置 API 凭证。CC 订阅路径需要先在此电脑完成 Claude Code 登录，再使用页面中的插件安装入口。
3. 在输入区下方选择可用模型和思考档位。菜单可按供应商筛选、搜索、收藏和翻页；收藏不切换模型。思考档位与回复详细程度在菜单底部展开，保留原有动画。

新会话使用上次成功选择的主模型；打开已有会话时保留该会话自己的模型。主模型与子 Agent 选择分别记忆，收藏列表共用。上次模型不可用时不会自动换成其他模型；初始化失败可主动清除偏好并重新连接。

本地档案中的名字或头像只用于个性化，不代表已经登录模型服务。连接远程模型后，请求会发送至该服务。

## 开始一项工作

选择项目或新建对话，告诉 Inkstone 你想完成的任务，并提供相关资料。例如：

> 帮我梳理这个项目的页面结构，先阅读 README，再列出需要完善的内容。

用 `@` 引用文件，用 `/` 查找可用命令，用 `!` 输入 Shell 命令。收到回复后，可以展开工具过程，或在工作面板中查看文件、打开浏览器与终端。

## 消息里的 HTML 成果

Agent 交付的 `.html` / `.htm` 成果会直接在消息卡片里显示网页，例如交互式架构图、图表或单文件报告。上方的「网页 / 源码」可以切换展示方式；原文件仍可下载，也可在右侧查看源码、打开所在位置或复制路径。

这是离线隔离预览，不是完整浏览器：支持内联脚本、样式和嵌入图片，但不加载网络资源或旁边的本地文件，不开放弹窗、表单提交、全屏及页面自行导出。页面的主题由它自身控制。HTML 需为受控成果附件，大小不超过 5 MiB；普通消息里的 HTML 代码块不执行。若页面尝试跳转后无法继续预览，可先切到「源码」，再切回「网页」重新加载。

## Codemode 工具调用

在 **设置 → 能力与插件 → Codemode** 中开启或关闭，默认开启，修改从下一轮对话生效。Agent 可以用脚本批量调用工具、处理结果，再把需要的内容带回对话；普通工具仍可直接调用。只读子 Agent 继续限制执行。旧计划模式已退出默认流程。

Codemode 使用 pi 原生能力，不是额外工作模式；显式停用原生 Codemode 扩展或使用旧 pi 时不可用。

## 会话切换器（Ctrl+K）

按 `Ctrl+K` 打开，不依赖左栏是否展开。输入几个词，就能同时搜会话标题、项目名和**对话内容**（所有词都出现才算命中），命中处会显示一小段原文；方向键选择，回车打开，`Esc` 关闭。没输入时列出最近的会话，直接回车就回到上一个会话。

对话内容的索引只在内存里，由本机的会话文件（pi 的 JSONL）生成，不上传。终端获得焦点时 `Ctrl+K` 留给 shell。

## 检查点与回退代码

每次你发出新一轮消息前，砚会给项目目录存一份文件快照（保存在数据目录下的影子 git 仓库里，与项目自己的 `.git` 无关），保留 30 天，只在本机。用户消息下方出现「回退代码」时，点它会先列出将修改、删除、恢复哪些文件，确认后再动；回退前会自动存下现在的状态，可以在确认框里「撤销这次回退」。

- 对话本身不会改变；要连对话一起回到那一轮，用同一行的「分支」。
- 能抓到 shell 命令造成的改动，不止 edit / write 工具；被 `.gitignore` 忽略的文件与 `node_modules` 不受影响。
- 项目是家目录或文件超过 3 万个时不做；可在 **设置 → 能力与插件 → 检查点** 关闭。
- 数据目录迁移（设置 → 关于）会把检查点连同会话文件（`sessions/` 下的 JSONL）一起搬走。

## 两档权限

输入区的权限选择器显示当前档位，对所有会话和普通子 Agent 生效：

- **危险批准**：常规操作直接执行，识别到明确危险操作时请求批准。
- **原生模式**：砚不额外审批或拦截；pi、Provider、外部工具和操作系统仍遵守自身行为。

批准卡显示来源会话、子 Agent 和执行目录；可识别来源时提供「查看来源」。无法识别时明确说明未知，不将其默认视为当前会话。底栏 WAIT 表示有请求待你处理，其他任务可能仍在运行。护栏不是沙箱，也没有额外的任务级权限档位。AskClaude 在 CC 内部执行，危险模式只能批准整次委派；需要逐条检查 pi 工具操作时使用指定 claude-bridge 模型的砚子 Agent。

## 没有安装 Git 的电脑

改动审阅、工作树、子任务隔离、检查点需要 Git，命令行工具在 Windows 上需要 Git Bash。电脑上没有时，砚会在启动后提示，并提供「一键安装 Git」：确认后从官方发布页（中文界面优先走国内镜像）下载约 57MB 的 PortableGit，校验通过后解压到砚的数据目录，不弹安装向导、不需要管理员权限、不改系统 PATH；电脑上已有 Git 时优先用它，不会覆盖。

不安装也能用：命令行工具会退到 Windows 自带的 PowerShell，模型会按 PowerShell 的写法执行命令，但改动审阅、工作树和检查点仍不可用。

## 当前会话界面与子 Agent

当前开发版默认只有会话入口，不再提供编码/日常、标准/计划/自主等叠加模式，也不提供独立空间、资料库、写作和学习页面。已有历史数据保留；写作、解释、学习和文件处理仍可在普通会话里完成。要求模型“先出计划，等我确认”属于会话指令，不等于宿主提供强制只读计划模式。

打开工具菜单中的「子 Agent」，选择模型、填写任务和执行方式。面板独立记住上次选择的模型，首次采用当前会话模型，也可明确选择「跟随当前会话」。表单显示实际模型与目录；结果回到父会话。当前文件夹会直接修改文件，只读限制工具，Git worktree 用于可选代码隔离并要求 Git。CC 订阅模型暂不支持只读子任务，选择时会提示；不支持的组合不能提交。

运行期间输入的新消息先进入待投递区，由用户选择插话或排队；停止按钮停止当前运行。切换会话不会停止后台任务。文件、浏览器、终端和子 Agent 详情按需打开，分屏下资源保持所属会话。

## 插件与远程连接

在「设置 → 插件市场」切换砚/pi 两页。砚页目前只有 Hermes 插件，导出插件不等于已安装或配对；pi 页支持搜索、安装、更新和卸载生态包，第三方包不保证图形兼容性。见[插件市场](PLUGIN_MARKET.md)。

Android 客户端处于测试阶段，连接电脑查看会话、发消息、回答问题与查看成果；任务仍在电脑执行。Android App 的敏感确认只能拒绝，同意需要电脑。独立 Hermes 插件提供用户明确允许/拒绝通道，须单独安装配对；普通模型回答不能代替批准。macOS/Linux/iOS 尚未交付，跨设备自动同步不提供。见[手机接入](MOBILE_ACCESS.md)。

## 常用操作

| 操作 | 入口 |
| --- | --- |
| 发送 / 换行 | 默认 `Enter` / `Shift+Enter`，可在设置中调整 |
| 文件引用 / 命令补全 | `@` / `/` |
| 两档权限 | 输入区权限选择器，对所有会话生效 |
| 模型与思考档位 | 输入区下方的选择器 |
| 切换会话（搜标题与对话内容） | `Ctrl+K` |
| 回退项目文件到某条消息之前 | 用户消息下方的「回退代码」 |
| 预览左栏（左栏收起时） | 鼠标停在标题栏左上角的开关上 |
| 界面缩放 | `Ctrl+=` / `Ctrl+-` / `Ctrl+0`（自动） |
| 界面语言与主题 | 设置中的外观选项 |

切换会话不会主动停止正在运行的任务；需要停止时，在对应会话中使用停止操作。

## 数据与备份

以下为未自定义数据目录时的默认位置：

| 版本 | 会话与模型凭证 | 应用设置 |
| --- | --- | --- |
| 单文件便携版 | EXE 旁 `砚数据/pi-agent/` | EXE 旁 `砚数据/yan/` |
| 安装版 / ZIP 版 | 用户目录下 `.pi/agent/` | 用户目录下 `.pi/agent/yan/` |

单文件便携版迁移时，关闭应用后连同整个 `砚数据/` 一起备份。安装版和 ZIP 版可备份用户目录中的 `.pi/agent/`；浏览器登录等 Electron 状态另存于应用数据目录，不包含在这份会话备份中。更完整的目录说明见[数据位置](dev/RELEASING.md#数据位置与备份)。

**迁移到其他磁盘**：安装版和 ZIP 版可在 **设置 → 关于 → 数据位置** 选一个空文件夹，应用重启时把整个数据目录搬过去，并在原位置留一个目录联接，旧会话与终端里的 `pi` 照常可用；复制核对无误后才删除原目录，失败会撤回。便携版与测试环境不能迁移。

**应用更新**：设置里可检查新版本。安装版下载后需你确认重启安装，有任务运行时会拒绝；便携版只提供 Release 页面入口。

备份可能包含 API 凭证、私人对话和浏览器状态，请妥善保存，勿上传至公开仓库或 issue。跨设备自动同步暂不提供。

# 开始使用 Inkstone

[返回主页](../README.md) · [English](GETTING_STARTED_EN.md)

## 安装与启动

从 [GitHub Releases](https://github.com/Yu-DaTouX/Inkstone/releases) 选择 Windows 发行包。下载前阅读该版本的发布说明；开发分支中的界面或功能可能尚未包含在发行包中。

| 版本 | 启动方式 | 适合的使用方式 |
| --- | --- | --- |
| 安装版 | 运行 `*-setup.exe` 并按安装向导操作 | 在常用电脑上使用 |
| ZIP 版 | 解压 `*-portable-fast.zip` 后运行 `砚.exe` | 解压后直接使用，无需安装 |
| 单文件便携版 | 运行 `*-portable.exe` | 携带应用及其旁边的数据目录 |

发行包已经包含 pi 运行时，无需安装 Node.js 或 pi。模型服务需要另外配置，额度和费用由所选服务决定。目前发行包未提供代码签名，请从本仓库发布页获取，并核对该版本提供的 `SHA256SUMS.txt`。

## 接入模型

1. 启动应用，打开 **设置 → 模型**。
2. 在「登录与订阅」「API Key」「自定义服务」中选择接入方式。CC 订阅需要先在本机登录 Claude Code；页面提供插件安装、版本来源与管理入口。自定义服务页也可检测本地模型，或打开本地工具下载页。
3. 在输入区下方选择可用模型和思考档位。菜单支持供应商筛选、搜索、收藏和连续滚动；收藏不切换模型。思考档位、回复详细程度和可视化回答开关在菜单底部。

新会话使用上次成功选择的主模型；打开已有会话时保留该会话自己的模型。主模型与子 Agent 选择分别记忆，收藏列表共用。上次模型不可用时不会自动换成其他模型；初始化失败可主动清除偏好并重新连接。

原生虚拟模型仍由 pi 注册和路由；回复尾部显示助手记录的实际模型，上下文窗口优先使用原生报告。只读子 Agent 不加载普通扩展，因此依赖它们的虚拟模型不可用时会明确失败，不改用其他模型。历史恢复交给 pi，缺少对应扩展时可能恢复最后记录的物理模型。

本地档案中的名字或头像只用于个性化，不代表已经登录模型服务。连接远程模型后，请求会发送至该服务。

## 开始一项工作

选择项目或新建对话，告诉 Inkstone 你想完成的任务，并提供相关资料。例如：

> 帮我梳理这个项目的页面结构，先阅读 README，再列出需要完善的内容。

用 `@` 引用文件，用 `/` 查找可用命令，用 `!` 输入 Shell 命令。收到回复后，可以展开工具过程，或在工作面板中查看文件、打开浏览器与终端。

## 澄清提问频率

当前开发版可在 **设置 → 会话 → 常规 → 澄清提问频率** 选择少问、适中（默认）或多问。模型菜单里的同名选项可为当前会话单独设置，或选择「继承」跟随全局；没有对应运行实例的历史预览不能修改。更改从下一轮生效，只调节模型指引，不保证精确次数，也不改变权限审批。新建、分叉和克隆会话默认继承全局。

运行中或需处理的子代理在输入框上方只显示一行数量概览。「查看」打开既有任务详情或子 Agent 面板，不在输入框上方展开第二套卡片。历史卡片留在原消息下，正常完成的任务不再常驻。

同项目会话的草稿文字和附件分别缓存；发送失败时恢复到发起会话，不填入后来切换的会话。路径或待落定身份的草稿只在能证明同一归属时迁移到正式会话 ID，旧缓存不覆盖目标已有草稿。缓存不替代磁盘备份。

同目录并行任务可能修改同一文件。创建实例时优先用 Git worktree 隔离；不能隔离、隔离目录也被占用或发送前发现同目录任务正忙时，明确拒绝并提示等待。worktree 不自动带入未提交文件，不是完整的文件锁，仍不能保证所有并发时序都无冲突。

## 消息里的 HTML 成果

Agent 交付的 `.html` / `.htm` 成果会直接在消息卡片里显示网页，例如交互式架构图、图表或单文件报告。上方的「网页 / 源码」可以切换展示方式；可重新加载或展开预览，也可在右侧查看源码、打开所在位置或复制路径；原文件仍保存在本机。

这是离线隔离预览，不是完整浏览器：支持内联脚本、样式和嵌入图片，但不加载网络资源或旁边的本地文件，不开放弹窗、表单提交、全屏及页面自行导出。页面的主题由它自身控制。HTML 需为受控成果附件，大小不超过 5 MiB；普通消息里的 HTML 代码块不执行。若页面尝试跳转后无法继续预览，可先切到「源码」，再切回「网页」重新加载。

## Codemode 工具调用

在 **设置 → 能力与插件 → 常规 → Codemode** 中开启或关闭，默认开启，修改从下一轮对话生效。Agent 可以用脚本批量调用工具、处理结果，再把需要的内容带回对话；普通工具仍可直接调用。只读子 Agent 继续限制执行。旧计划模式已退出默认流程。

Codemode 使用 pi 原生能力，不是额外工作模式；显式停用原生 Codemode 扩展或使用旧 pi 时不可用。

## 上下文与压缩

在 **设置 → 会话 → 上下文与记忆** 调整自动压缩和旧工具输出省略。压缩由 pi 原生执行；砚默认在整轮结束后达到 400k token 时提前触发，小窗口模型按窗口的 90% 限制。省略旧工具输出默认软线为 80k，小窗口按比例降低，并根据缓存时机分批处理；不改聊天记录或原文件，也不保证每轮费用更低。两项都可关闭，细节见[架构边界](ARCHITECTURE.md#职责)。

输入框下方的会话统计入口可查看轮数、模型请求步数、模型/工具用时、平均首 token 延迟（TTFT）与输出速度；旁边的 Token 用量入口显示会话累计输入、输出及缓存明细，可在设置中关闭。累计调用 Token 不等于当前上下文占用，后者仍由上下文圆环显示。缺报值显示「—」，已知累计下限标「≥」；旧历史没有记录的计时不会补造。状态栏花费详情也采用本会话累计口径，服务报零不表示实际免费。

旧「项目知识 / 个人记忆」确认页面已退出默认界面，不要将保留的历史数据格式误认为现行入口。

## 书签与互动状态

会话柄预览中的书签会保存在本机，按会话与消息区分，重启后可读回。小部件标题行的「保存状态」保存表单值和可选 JSON 状态；重新加载会恢复，未保存的操作仍会丢失。「填入输入框」只放入已保存状态，不自动发送。密码、隐藏域和文件输入不采集，每个小部件上限 64 KB。

## 本地备份

在 **设置 → 关于 → 本地备份** 点「创建备份」，选择保存位置。砚新建备份子文件夹，保存会话、桌面设置、书签和小部件状态，并校验 SHA-256；不含凭证文件、附件、模型或项目文件，不能当作整机备份。内容仍可能有敏感信息，请妥善保存，尽量在空闲时操作；复制期间源文件变化会报错并保留不完整副本。

「校验备份」选择已有备份文件夹，只核对清单、文件大小和摘要，不覆盖当前数据。自动恢复/切换尚未提供；不要把校验通过理解成已经恢复。

## 会话切换器（Ctrl+K）

按 `Ctrl+K` 打开，不依赖左栏是否展开。输入几个词，就能同时搜会话标题、项目名和**对话内容**（所有词都出现才算命中），命中处会显示一小段原文；方向键选择，回车打开，`Esc` 关闭。没输入时列出最近的会话，直接回车就回到上一个会话。

输入 `>` 切换到动作模式；固定操作与原生斜杠命令共用已有入口。`Ctrl+/` 打开快捷键表，设置页也可查看；`Ctrl+,` 打开设置，`Ctrl+B` 切换左栏，`Ctrl+L` 聚焦输入框，`Ctrl+Shift+C` 复制末条回复。模态框、输入法及终端持有按键时不抢新增快捷键；未新增全局 Esc 停止操作。图标按钮的提示支持悬停与键盘聚焦，删除等操作使用取消优先的应用内确认框；不完整可恢复的操作不承诺撤销。

对话内容的索引只在内存里，由本机的会话文件（pi 的 JSONL）生成，不上传。终端获得焦点时 `Ctrl+K` 留给 shell。

## pi 原生会话操作

当前开发版在输入框和 Ctrl+K 命令模式中提供：

- `/tree`：查看原生条目树与当前位置，方向键选择/折叠，Enter 导航；不会自动请求分支摘要。它不是已退役的跨会话地图。
- `/import [文件路径]`：选择或指定 JSONL，校验后创建独立会话副本并打开，原文件保留；副本使用新会话 ID，避免与已有会话混在一起。
- `/export [文件路径]`：默认 HTML；指定 `.jsonl` 时导出当前实时分支（含该分支压缩前记录），覆盖已有文件需确认。HTML 按 pi 原生格式包含整个会话树与当前叶子。
- `/compact [要求]`：将附加要求传给 pi 原生压缩。`!命令` 将 shell 结果放入模型上下文；`!!命令` 执行并保存，但不放入模型上下文。
- `/reload`：原生热重载扩展、技能、模板与上下文文件，以完成回执为准。`/new [父会话路径]` 可附带原生父会话记录。
- `/scoped-models`：保存 pi 用户级 `enabledModels`，约束 Ctrl+P 循环范围；`/trust`：人工确认后信任或撤销当前目录。会话已保存时重新创建该空闲 pi 实例后应用，不重启桌面窗口；尚未落盘时只保存设置并明确提示需重建 pi 实例，单独 `/reload` 不会应用模型范围或信任变化。项目配置覆盖模型范围时报告，不假装应用成功。
- `/share`：人工确认后用已安装并登录的 GitHub CLI 创建非公开 gist。上传的 HTML 包括已放弃分支、系统提示、工具定义等，可能含凭证；非公开不代表秘密，分享前检查内容。当前不接 Radius 上传，不自动登录或上传。

替换会话、导航、重载及设置应用在运行、排队或等待答复时拒绝；命令失败保留草稿。扩展的纯文本组件按原生 `aboveEditor` / `belowEditor` 显示，不支持 pi RPC 本身没有提供的 TUI 自定义组件。

## MCP 与终端运行状态

新通用 MCP 使用 pi 原生配置。设置的兼容服务可逐条「导入到 pi」：先核对本条配置、目标文件与提醒，再确认提交；写入、校验和停用旧条目分别回报，部分失败不抹去已写入事实。`authRef` 凭证不迁移，可能需要在 pi 重新登录；`windows-mcp` 保留。请在任务空闲时导入，旧连接会断开，新连接等 pi 下次加载配置，不自动重启当前实例。没有显式确认不会自动迁移。

普通终端只有程序主动报告才显示运行、等待、完成或错误；终端存活不等于正在运行任务。Windows 任务栏进度与等待角标使用现有运行事实；后台终端进入等待时按现有通知设置提醒。无报告的 shell 不显示伪造的「运行中」。

## 更改项目文件夹

在左栏打开项目的菜单，选择 **更改项目文件夹…**，输入或选择已有文件夹，再点 **保存目录**。

这只更改该项目后续新建会话的默认目录，保留项目名称、分组、排序和已有索引中的会话归属。磁盘文件不搬动，旧会话仍在原目录执行，运行中任务不切换或停止；新目录也不会自动获得信任。需要在新目录工作时，从该项目菜单新建会话，而不是继续旧会话。

目录不存在、不可访问，或已被其他项目（含归档项目、目录链接）使用时，会显示错误，不自动合并项目。此入口不是全量历史迁移工具，不批量重写旧会话或补迁常规列表范围之外的未索引记录。

## 检查点与回退代码

你发出新一轮消息前，砚会尝试为符合条件的项目目录保存文件快照（保存在数据目录下的影子 git 仓库里，与项目自己的 `.git` 无关），保留 30 天，只在本机。用户消息下方出现「回退代码」时，点它会先列出将修改、删除、恢复哪些文件，确认后再动；回退前会自动存下现在的状态，可以在确认框里「撤销这次回退」。

- 对话本身不会改变；要连对话一起回到那一轮，用同一行的「分支」。
- 能抓到 shell 命令造成的改动，不止 edit / write 工具；被 `.gitignore` 忽略的文件与 `node_modules` 不受影响。
- 项目是家目录或文件超过 3 万个时不做；可在 **设置 → 能力与插件 → 常规 → 代码回退** 关闭。
- 数据目录迁移（设置 → 关于）会把检查点连同会话文件（`sessions/` 下的 JSONL）一起搬走。

## 两档权限

输入区的权限选择器显示当前档位，对所有会话和普通子 Agent 生效：

- **自动批准**（危险审批）：常规操作直接执行，识别到明确危险操作时请求批准。
- **不受限制**（原生模式）：砚不额外审批或拦截；pi、Provider、外部工具和操作系统仍遵守自身行为。

批准卡显示来源会话、子 Agent 和执行目录；可识别来源时提供「查看来源」。无法识别时明确说明未知，不将其默认视为当前会话。底栏 WAIT 表示有请求待你处理，其他任务可能仍在运行。护栏不是沙箱，也没有额外的任务级权限档位。AskClaude 在 CC 内部执行，危险模式只能批准整次委派；需要逐条检查 pi 工具操作时使用指定 claude-bridge 模型的砚子 Agent。

## 没有安装 Git 的电脑

改动审阅、工作树、子任务隔离、检查点需要 Git，命令行工具在 Windows 上需要 Git Bash。电脑上没有时，砚会在启动后提示，并提供「一键安装 Git」：确认后从官方发布页（中文界面优先走国内镜像）下载约 57MB 的 PortableGit，校验通过后解压到砚的数据目录，不弹安装向导、不需要管理员权限、不改系统 PATH；电脑上已有 Git 时优先用它，不会覆盖。

不安装也能用：命令行工具会退到 Windows 自带的 PowerShell，模型会按 PowerShell 的写法执行命令，但改动审阅、工作树和检查点仍不可用。

## 当前会话界面与子 Agent

当前开发版默认只有会话入口，不再提供编码/日常、标准/计划/自主等叠加模式，也不提供独立空间、资料库、写作和学习页面。已有历史数据保留；写作、解释、学习和文件处理仍可在普通会话里完成。要求模型“先出计划，等我确认”属于会话指令，不等于宿主提供强制只读计划模式。

打开工具菜单中的「子 Agent」，选择模型、填写任务和执行方式。面板独立记住上次选择的模型，首次采用当前会话模型，也可明确选择「跟随当前会话」。表单显示实际模型与目录；结果回到父会话。当前文件夹会直接修改文件，只读限制工具，Git worktree 用于可选代码隔离并要求 Git。CC 订阅模型暂不支持只读子任务，选择时会提示；不支持的组合不能提交。

全应用最多同时运行24个子 Agent。工具调用次数由模型按任务需要决定；没有工具正在执行时，连续10分钟没有模型输出或工具事件后请求收尾；工具正在执行时，停滞阈值延长至约60分钟。请求收尾后75秒内仍未结束才停止。持续有进展时默认没有总期限；模型通过请求参数仍可明确指定总期限。

子 Agent 的最近调用过程和最终回复保存在本机，重启后仍归原会话，点击任务卡标题查看过程；完整任务说明保留在卡片的「详情」里，过程窗口不再另设任务原文按钮。旧版记录会尝试从仍存在的子任务原生会话补回过程，缺失内容不编造。重启只恢复历史，不自动重新执行任务或发送完成通知。

运行期间输入的新消息先进入待投递区，由用户选择插话或排队；停止按钮停止当前运行，并取消该会话的宿主生图等待，不再挂出迟到结果。已发到云端的请求不保证免计费；ComfyUI 只撤销本次排队项，已经执行的工作流不做全局中断，以免误停其他任务。切换会话不会停止后台任务。文件、浏览器、终端和子 Agent 详情按需打开，分屏下资源保持所属会话。

## 插件与远程连接

设置长页通过顶部主题页签切换，同一页面内切换保留未保存表单；低频说明与目录默认折叠。OpenCLI 安装/更新和 Chrome 扩展下载在「能力与插件 → 搜索与浏览器」；「查看官方版本」打开发布方页面，不代表自动检测到新版本。

在「设置 → 插件市场」切换砚/pi 两页。砚页目前只有 Hermes 插件，导出插件不等于已安装或配对；pi 页支持搜索、安装、更新和卸载生态包，第三方包不保证图形兼容性。见[插件市场](PLUGIN_MARKET.md)。

Android 客户端处于测试阶段，连接电脑查看会话、发消息、回答问题与查看成果；任务仍在电脑执行。Android App 的敏感确认只能拒绝，同意需要电脑。独立 Hermes 插件提供用户明确允许/拒绝通道，须单独安装配对；普通模型回答不能代替批准。macOS/Linux/iOS 尚未交付，跨设备自动同步不提供。见[手机接入](MOBILE_ACCESS.md)。

| 模型与思考档位 | 输入区下方的选择器 |
| 切换会话（搜标题与对话内容） | `Ctrl+K` |
| 回退项目文件到某条消息之前 | 用户消息下方的「回退代码」 |
| 预览左栏（左栏收起时） | 鼠标停在标题栏左上角的开关上 |
| 界面缩放 | `Ctrl+=` / `Ctrl+-` / `Ctrl+0`（自动） |
| 界面语言与主题 | 设置中的外观选项 |

切换会话不会主动停止正在运行的任务；需要停止时，在对应会话中使用停止操作。

## 数据与备份

以下为未自定义数据目录时的默认位置：

| 版本 | 会话与模型凭证 | 应用设置 |
| --- | --- | --- |
| 单文件便携版 | EXE 旁 `砚数据/pi-agent/` | EXE 旁 `砚数据/yan/` |
| 安装版 / ZIP 版 | 用户目录下 `.pi/agent/` | 用户目录下 `.pi/agent/yan/` |

单文件便携版迁移时，关闭应用后连同整个 `砚数据/` 一起备份。安装版和 ZIP 版可备份用户目录中的 `.pi/agent/`；浏览器登录等 Electron 状态另存于应用数据目录，不包含在这份会话备份中。更完整的目录说明见[数据位置](dev/RELEASING.md#数据位置与备份)。

**迁移到其他磁盘**：安装版和 ZIP 版可在 **设置 → 关于 → 数据位置** 选一个空文件夹，应用重启时把整个数据目录搬过去，并在原位置留一个目录联接，旧会话与终端里的 `pi` 照常可用；复制核对无误后才删除原目录，失败会撤回。便携版与测试环境不能迁移。

**应用更新**：设置里可检查新版本。安装版下载后需你确认重启安装，有任务运行时会拒绝；便携版只提供 Release 页面入口。

备份可能包含 API 凭证、私人对话和浏览器状态，请妥善保存，勿上传至公开仓库或 issue。跨设备自动同步暂不提供。

本目录只负责回答“接下来还要做什么”。当前状态、验证基线和六栏证据以
[HANDOFF](../dev/HANDOFF.md) 为准；代码定位看 [PROJECT](../PROJECT.md) / [CODE-MAP](../dev/CODE-MAP.md)，

## 使用规则

1. 开工前先读 [AGENTS.md](../../AGENTS.md)、[HANDOFF](../dev/HANDOFF.md)，再看本页和目标主题。
2. 只从 `active/` 选择未完成主题；每个会话切片完成后回填 HANDOFF 的六栏证据。
3. `docs/archive/` 下的计划、证据和外部参考只用于追溯，不是当前待办，也不把旧文件里的命令当作本轮授权。
4. 同一主题只保留一份正文；活动主题在 `active/`，完成主题在 `archive/plan/`，验收证据在 `archive/evidence/`。

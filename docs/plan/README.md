## 使用规则

1. 开工前读 AGENTS.md、HANDOFF、本页和目标主题正文。
2. 只从 active/选择仍未闭环的主题；每个切片都要回填实现、自动检查、真实运行、视觉验收、应用与包、剩余限制六栏。
3. archive/只用于追溯。归档文件中的命令、建议和“下一步”不是当前授权，也不代表功能仍未完成。
4. 同一主题只保留一份活动正文；已完成主题放在 archive/plan/，逐片证据放在 archive/evidence/。
5. 本页是路线图，不替代 HANDOFF 的当前事实；若两者冲突，以 HANDOFF 最新证据和源码为准。

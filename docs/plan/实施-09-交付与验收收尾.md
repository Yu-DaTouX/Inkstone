## 1. 第一块 · 两条真的遗留缺陷（2026-09-18 核查时发现，**不是**方案引入的）

| 项 | 现象与已查到的线索 | 修法要求 |
|---|---|---|
| **fs 文件树的键盘导航** | `End` 从根出发时焦点掉到 **body**（不是「没渲染」——诊断打出 `DOM 行数=50`、最后一行 `tsconfig.web.tsbuildinfo` 就在 DOM 里）。同一节里「Home 回到树根」「ArrowRight 从已展开目录移动到下一可见节点」**都通过**，所以**从已聚焦行出发**的移动是好的 | 问题只在「先 focus 另一行、再派发按键」这条路径：`row.focus()` → `onFocus` → `setFocusPath` → 重渲染，而 `focusTreePath` 的焦点恢复写在 `requestAnimationFrame` 里，查到 / 聚焦的可能是**被替换掉的节点**。**已试过的方案已撤回**（`useLayoutEffect` + 键盘意图哨兵 → `End` 仍红，`ArrowRight` **反而变红**）。**下一步必须先有逐帧观测**（打 `activeElement` 时间线），否则「修一处坏一处」。**✅ 已修（2026-09-19）**：逐帧观测推翻了上面的假说，真因是**两套顺序**（`visiblePaths` 严格 DFS vs `budget` 父层先扣额度）—— 键盘能走到没渲染的行，`focus()` 静默失败 |
| **窄窗口下左栏收起的 48px 残留** | 宽窗口收起是 0，**窄窗口（≤1002px）稳定停在 48px** —— 不是动画中间值，是**紧凑轨移除时没清掉的那一列宽度** | 修的是**窄窗媒体查询里写死的那个值**（在 `layout.css`，不是 `rail.css` 的列定义）：它必须留着以压过同媒体查询里 `.workspace` 自己的 `min()` 声明，但值要跟 `--w-rail-collapsed` 走。`narrow` 的断言已改成意图级并**打印实测值**；**✅ 已修（2026-09-19）**，断言已收回硬值 0 |

**出口**：两条各有一份「改动前 → 逐帧观测 / 列宽实测 → 改动后」的证据；
`fs` 与 `narrow` 场景真实变绿（**不是**改断言变绿）。

> ✅ **已达成（2026-09-19，一轮完成）**。证据全部登记在
> [HANDOFF「本轮（2026-09-19）实施-09 S1」](../dev/HANDOFF.md) 的六栏表里。要点：
> ① 窄窗 48px 的真因是**窄窗媒体查询里写死了旧紧凑轨的宽度**（不是 `rail.css` 的列定义，修正本表旧描述），
> 位置在 `layout.css` 的两处 `@media`；改走 `--w-rail-collapsed` 后 `narrow` 三档窗口实测全 `0px`，
> A/B（临时改回 48px）能真实变红。
> ② fs 那条**不是焦点管理** —— 原假说（rAF 里聚焦到被替换的节点）被逐帧观测推翻：
> 真因是 `visiblePaths`（严格 DFS）与渲染截断（跨层级 `budget`，父层先扣额度）**用了两套顺序**，
> 键盘能走到没渲染出来的行，`focus()` 静默失败。改成渲染直接依据 `visibleSet` 后 `fs` 全部通过。
> 剩下的第 3 条红（鼠标收起）是**测试没模拟真实鼠标的默认聚焦**，已按真实行为修正探针（附条件轮询）。

### S3 的口径（2026-09-18 定）

**不新建状态真源。** 会话文件是唯一真源，`lastSessionId` 会造成**双写一致性问题**。

- 只在会话文件里补 **`lastOpenedAt`**（单调序号或显式时间戳）；
- 启动 / 切回项目时**扫描目录推导**「最近的会话」；
- **不要**依赖文件 `mtime` —— 复制、恢复备份、系统时钟变化都会污染排序；
- 草稿不丢仍靠「切走 / 回收前强制落盘」，`lastOpenedAt` 只解决**恢复哪一个**的问题。

## 7. 执行注意（踩过的坑）

1. **`test:live` 不会自动构建** —— 改完 `src/` 必须先 `npm run build`，否则验的是旧 `out/`。
2. **跑 Electron 前清掉 `ELECTRON_RUN_AS_NODE`** —— `export ELECTRON_RUN_AS_NODE=`（空串）**也算设置**，
   只能用 `env -u ELECTRON_RUN_AS_NODE`，否则 `measure:design` 报
   `does not provide an export named 'BrowserWindow'`。
3. **旧产物存在 ≠ 构建成功** —— 下结论前确认时间戳是本次构建的。
4. **cost 1 场景先设 `YAN_TEST_MODEL`** —— 免费模型日配额（429）或上游状态会让场景假红；
   看到 429 直接停手（每跑一次都在烧剩余额度）。
5. **`todos` 的红是产品边界下的陈旧失败** —— 不要为了让场景变绿去改任务面板。

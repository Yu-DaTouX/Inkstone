## 1. 边界和交付方式

- 用户已确认收起的是**左侧项目栏**；只收回“更多会话”，不是关闭项目或任务。
- 目标浮层改 GoalState 的展示；既有 todo 任务面板及宿主任务服务不重构。
- 首期磁贴采用单列停靠 + 应用内浮动，不做 docking 树、跨窗口/跨屏拖放。
- 应用布局状态与业务状态分开；会话正文、凭证、真实任务状态不写进布局。
- 新方案不追溯重开已完成工程；实现者需先读当前 HANDOFF 和脏工作树，确认其它 agent 是否已补交对应片段。

## 3. 每片执行卡

### U-0 · 布局契约与迁移

输入：设计 §5.3、既有 AppSettings、workbench.ts、toolOrder/toolHidden 的读写点。先查明设置规范化/写盘函数位置，提交文件域清单后开工；不另造 localStorage + settings 双真源。

步骤：定义可移动磁贴 registry 与 placement 联合类型；确定应用级布局/会话级内容边界；实现旧字段只读迁移、未知 ID 过滤、重复归一、rect 夹取、revision 最新写；将 UI 使用的布局选择器改成唯一新入口。H-3 资源布局只引用磁贴布局，不保存另一份位置。

出口：旧配置顺序/隐藏逐项保留；重复 ID 只一份；无效坐标恢复可见；连续拖动的晚返回不覆盖新位置；恢复默认不改变业务数据。单测覆盖迁移、归一、版本未知与并发写；一条隔离 Electron 保存→重启→读回证据。未接磁贴视图前状态写“契约完成，界面待 U-4”。

### U-1 · 左栏更多会话复位

输入：Rail 的 `expanded-sessions`、App 的 railPinned；先确认 sidebar 偏好的项目/窗口作用域。

步骤：通过左栏 true→false 转换重置更多会话；保留其它展开字段；关闭临时菜单。不能在 render 中写状态，也不能依赖组件卸载偶然触发。

出口：两个项目分别展开更多→收左栏→再开，各恢复 SESSION_PREVIEW；右栏收起不影响；搜索中收起后搜索结果仍完整，清搜索才按预览；运行任务/选中项/项目分组不变化。扩展现有 railmini/railsearch 或新增 cost 0 场景，记录关键断言；无需调用模型。

### U-2 · 项目上下文菜单

输入：设计 §3.2、现有项目动作；依赖 H-9a 可取得/释放 overlay blocker。

步骤：项目 ID 与 anchor 分开保存；Portal 定位；统一右键/省略号/键盘入口；roving focus、焦点恢复、外点关闭；保留重命名/移除等原 action 的权限与错误处理。第一片只迁项目菜单，分组/会话菜单若复用同组件则同步验收，否则列清残余，禁止半换样式冒充全覆盖。

出口：四角、窄窗、缩放 150%、长路径均可操作；项目行 y 与 scrollHeight 无布局变化；不误触拖排序/切项目；键盘可完成打开、选项、取消；浏览器与另一浮层同时存在时显隐正确。真实深浅截图各一组。

### U-3a · 目标浮层与文本

输入：GoalSection、GoalState、现有目标设置动作、设计 §4。共用短标题函数由本片实现，H-10a 消费；原始目标与 outcome 不修改。

步骤：提取只读 GoalContent；标题栏入口负责开闭，取消 tools 页里常驻的重复目标块；任务清单仍读 steps；产物/参考先空态、已有字符串证据保留出口；支持原文展开与长任务滚动。状态加载加会话/goalId 的 stale guard，失败可重试，不能把加载失败显示成“暂无目标”。

出口：无目标、计划中、执行中、核验、受阻、停止、完成各态；完成数正确；空标题/超长标题/emoji；目标切换不会展示前一会话证据；点击查看不会创建/停止目标；todo 原功能回归。复用 goal 探针前核对 cost；纯展示新增 cost 0 fixture，不将其称为真实自主执行。

### U-3b · 产物与参考的真实归属

输入：真实 goal report 协议和 goal-store 序列化位置；不要只在 renderer 扫描 evidence 字符串。

步骤：增加可选结构化链接并版本兼容读取；宿主校验 kind、归属和输入上限；从现有可信消息/报告显式登记；不新增 pi 工具。设计给出的结构是最小需求，字段落地前先确认 current report 契约。

出口：旧 goal 无 links 能读；文件缺失可重试；相对路径按来源解析且仍通过宿主校验；不支持的 scheme 不执行；A/B 目标链接隔离；只有真实登记的数据计入产物/参考。单测协议与旧存储，cost 0 真 IPC + 文件点击；真实模型报告消费另列需要额度的行为证据。

### U-4 · 工具页与键盘可移动磁贴

输入：U-0 新布局、H-3b 开始/工具导航、ToolLibrary 与 TOOL_SECTIONS。先复用现有 ContextSection/额度/队列内容，禁止重写 C-5 容量分母和统计来源。

步骤：稳定工具库目录、单实例磁贴容器；按钮可停靠、浮动、定位、收纳；可浮动 registry 明确排除 todo/完整文件树；键盘移动与拖放共用命令。先把按钮路径做通，随后 U-5 仅增加手势。

出口：每项最多一个内容实例；迁移后旧排序一致；无数据磁贴有空态；隐藏/浮动不多订阅、不重复请求；会话切换重新绑定上下文；键盘完整完成移出和放回；contextbudget、tools 等既有回归通过。

### U-5 · 拖放与几何恢复

输入：设计 §5.2/5.4，U-4 所有按钮路径已通过。

步骤：pointer 阈值与 capture、插入线、拖影、drop zone、非法区域回滚、cancel 完整清理；原生网页暂隐与放置避让；可用内容区变化夹取位置；完成后一次性保存。跨容器拖动中源工具库不因外点关闭而卸载。

出口：工具页→浮动→工具页/库循环；Esc/失焦/切会话取消；点正文可选字；拖后不误点按钮；网页运行状态保留；所有磁贴不会随缩窗丢到屏外；重启恢复；只在 commit 写盘。纯函数测几何/状态机，真 Electron pointer 操作测捕获/焦点，截图核对层级。

### U-6 · 联调与交付

输入：每片六栏记录。执行“左栏展开更多→开项目菜单→开目标→打开网页→拖上下文→查看子代理→切会话→重启恢复”的完整操作路线。

出口：无跨会话数据泄漏、无原生视图遮挡、无重复面板/滚动条；真实窗口深浅/窄矮/缩放矩阵已看图；写明开发应用是否已通过根启动入口应用。包未重跑就明确标注，发布门槛仍由实施-09 持有，不因 UI 文档重启发布工作。

## 4. 调度与 agent 交接

| 可独立处理的工作 | 条件 |
|---|---|
| U-1 与全局 V-0 盘点 | 前者改 Rail，后者仅做证据/清单，不抢文件 |
| U-3b 与 H-10b 数据层 | shared/ipc.ts、store.ts、测试注册只由一个集成 owner 修改 |
| 全局 V-3 设置与 U-5 拖放 | 公共令牌/组件已经冻结，不改 RightPanel/公共 overlay |

RightPanel、store、SessionHeader、shared/ipc、i18n、tokens、visual-matrix 都是共享热点；**同一波只有一个写入 owner**。其它 agent 提交字段需求或独立模块后由 owner 接线。上表是供用户分派的计划，本轮不启动子代理。

每个 agent 接单说明必须包含：切片 ID、前置已达到的证据、允许修改的文件域、禁止范围、设计章节、验收用例、六栏回填位置。发现前置未完成时先报告具体缺口，不绕过前置重建第二套状态。

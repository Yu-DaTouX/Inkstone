- 用户已确认收起的是**左侧项目栏**；只收回“更多会话”，不是关闭项目或任务。
- 目标浮层改 GoalState 的展示；既有 todo 任务面板及宿主任务服务不重构。
- 首期磁贴采用单列停靠 + 应用内浮动，不做 docking 树、跨窗口/跨屏拖放。
- 应用布局状态与业务状态分开；会话正文、凭证、真实任务状态不写进布局。
- 新方案不追溯重开已完成工程；实现者需先读当前 HANDOFF 和脏工作树，确认其它 agent 是否已补交对应片段。

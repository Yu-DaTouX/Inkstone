## 2. 具体优化目标

| 区域 | 明确的最终行为/视觉 | 保留边界 | 实施位置 |
|---|---|---|---|
| 全局层级 | 主内容最清晰，辅助元信息用次级文字；只用一种主强调色；每个区块一个主要边界，去除重复嵌套描边 | 不重换字体体系/配色方向 | tokens.css、shell/layout、DESIGN |
| 标题栏 | 标题弹性占位，目标/子代理/栏开关固定可达；窄窗先省略标题，再收次操作至更多菜单 | Windows 窗口按钮与拖动区域不被覆盖 | SessionHeader、TitleBar、shell/rail |
| 左栏 | 项目/会话层级靠缩进、字体与选中底区分；hover 才显示次操作，但键盘聚焦始终可见 | 项目排序/分组/真实运行状态保留 | Rail、rail.css；新增行为归 U-1/U-2 |
| 对话正文 | 保持当前内容宽度和低对比用户块；段落、列表、代码块、表格有统一间距；长 URL/代码不撑开主列 | 消息 JSONL 真源、推理展开规则保持 | MessageParts、TurnView、chat/tools |
| 工具/推理行 | 一行摘要清楚显示动作与结果，状态不只靠颜色；默认/主动展开高度遵循既定规则 | 不恢复无界展开，不改最新内容贴底 | ToolRow/工具组、tools.css |
| 输入区 | 文本、附件、模式/模型、发送各有固定职责；错误就地、发送/停止不跳位，窄窗次操作收纳 | 不把耗时放回输入框下，不改发消息语义 | Composer、composer.css |

## 3. 固定实施基线

1. 使用 DESIGN 现有字号 13/14/12.5px 层级、左 248/右 320/内容 800px 基线；只在测量证明影响可用性时新增组件级变量，不全局放大字号掩盖布局错误。
2. 新增控件候选尺寸：普通按钮高 32px，紧凑图标命中区至少 28px，菜单行 32px，设置行最小 56px（多行说明自动增高），区组间距 24px、行间 12px。先复核密度设置的已有变量，再把必要值写进 DESIGN；禁止各页各造同义 token。
3. 普通文本与背景对比度目标 ≥4.5:1，大文本和功能图形 ≥3:1；禁用不能只降低到看不见。focus-visible 使用清楚的 2px 轮廓并留 2px 偏移，检查不会被 overflow 裁掉。
4. 只保留 hover/focus/按下/展开的必要动效，建议 120–180ms；reduced-motion 下关闭位移/扩张；不为装饰引入新的持续动画。已有 Orb 不因本方案撤换，但不得驱动列表重排。
5. 窄窗用有优先级的收纳，不仅缩字号：隐藏次级标签文字→次操作更多菜单→内容滚动；发送/停止、当前状态、关闭、返回保持可达。不能凭 hover 才能找回核心功能。
6. 中英文与长路径都必须测。状态文案区分加载、空、错误、未接入；没有数据不画 0%，没有实际快捷键不展示快捷键。

## 5. 验收矩阵和完成判据

| 组合 | 范围 |
|---|---|
| 深/浅 × 1440×900 ×100% | 所有被改页面与空/加载/错误/成功/禁用/focus 态 |
| 深/浅 ×940×620 和900×520 | 主界面、设置、浮层、开始页、磁贴、子代理 |
| 125%/150% | 标题/菜单/设置、原生浏览器边界与拖放；不必无变化重复全量场景 |
| compact/standard/comfortable | 被改公共控件和主布局，验证已有密度行为不回归 |
| 键盘/reduced-motion | 菜单、目标、工具、设置、子代理主要路线，无焦点陷阱 |

正常主窗口 horizontal overflow=0；代码/表格/树在明确内部容器中可横滚。浮层与动作按钮不能越出可用区；几何误差上限 1 CSS px（原生 bounds 按实际缩放取整记录）。视觉复核需真正看图，不以测量结果代替。

沿用现有 layout/light/dialog/settings/density/railtitle/toolrow 等成本 0 场景；实施前核对 CASES，新增覆盖先注册。测试使用隔离 YAN_*、默认隐藏；截图需要显式视觉流程。真实模型/生成图片不是本轮全局美化的自动前置。

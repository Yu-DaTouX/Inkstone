# Inkstone · 砚：品牌与项目主页

本页维护公开品牌命名、主页文案与素材使用规则。UI 设计令牌仍以 [DESIGN](DESIGN.md) 为准；图标路径以 [提示砚图标准则](active/图标设计与应用准则-2026-09-21.md) 指定的源文件为准。

## 名称与定位

- 英文产品名：**Inkstone**（用户于 2026-09-24 确定）。
- 中文产品名：**砚**。首次介绍写作 **Inkstone（砚）**；组合署名使用 **Inkstone · 砚**。
- 中文定位：**一个专注于内容与行动的桌面 AI 工作空间。**
- 英文定位：**A desktop AI workspace for thinking, making, and moving work forward.**
- `Yan` / `yan` / `YAN_*` 等已有工程标识、CLI、数据目录及仓库地址继续按现有实现使用；品牌命名不构成这些接口的迁移。

## Slogan

本轮主页采用以下文案，后续品牌评审可继续调整：

> **让想法成形。**
>
> **Give ideas form.**

“想法”对应对话与输入，“成形”对应文件、代码、计划和其它产出；措辞覆盖创作与开发，也呼应砚承接笔墨的名称意象。它表达使用愿景，不作为自动完成、正确性或交付质量承诺。

“墨色工作空间”是视觉设计概念，在设计说明中使用。主页以短 slogan 传达价值，以产品定位说明用途，两者不重复堆叠。

## 视觉组合

1. **图标来源。** 使用 [build/prompt-stone.svg](../../build/prompt-stone.svg) 的原始路径；保持开口、端点、线宽与内部比例。首页横向组合中的图标仅等比缩放。
2. **英文标题。** Inkstone 使用完整、自然比例的无衬线轮廓，避免逐字拆装和强行几何变形。当前基底为 Segoe UI Semibold，导出为路径后不依赖访问者的字体。
3. **中文名称。** 以正常可读文本呈现；本轮主页不采用此前变形的中文实验字标。
4. **图文比例。** 图标可见高度 112，英文可见高度 82，图文间隔 36；画布 800 × 184。以视觉中心对齐，保留充足空白。
5. **色彩可换。** 本轮深浅版采用中性墨色和暖白用于适配背景，不将其定为不可修改的品牌色。图标与英文共用 `currentColor`；SVG 根 `color` 是整组唯一前景色入口。
6. **图标与主视觉分工。** 矢量字标保持纯色与原始几何。主页横幅采用用户提供的纸墨砚台图片，经内置 imagegen 编辑为 2172 × 724 横幅；保留纸张、石材与墨迹，移除边角小字和装饰线。该插画不替代应用图标。产品 UI 截图保留应用自身的强调色和状态色。

## 主页结构与文案

顺序为：品牌标题 → slogan 与定位 → 下载 / 开始 / 文档入口 → 深浅界面预览 → 工作价值与能力 → 设计理念 → 开始使用 → 数据与平台 → 贡献与许可。

- 默认中文 [README](../../README.md)，独立 [English README](../../README_EN.md) 避免整页逐句双语重复。
- 标题采用动词和用户任务；技术栈放在开发段落。
- 对外首页面向使用者；开发说明折叠在页尾。内部交接、阶段验收、实施计划与调试记录通过工程文档索引访问，不进入产品介绍正文。源码保持正常开源入口，不能将展示内容筛选等同于删除工程资料。
- 已实现能力与发布内容分开说明，主页截图标明开发分支和演示数据。
- 不写未验证的性能数字、绝对隐私承诺、“全自动交付”或“所有平台可用”。
- 只用 GitHub 支持的 Markdown / HTML；`picture` 选择深浅素材，保留 `img` 回退与替代文本。

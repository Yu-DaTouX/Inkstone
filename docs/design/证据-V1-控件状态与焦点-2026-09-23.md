日期：2026-09-23 ｜ 归属：实施-13 V-1 ｜ 依赖：V-0（[基线盘点](证据-V0-UI基线盘点-2026-09-23.md)）

V-1 的任务是「统一按钮、文本框、搜索框、select、分段控件、提示和焦点态；同一危险/禁用/
加载样式只有一个来源」，并且**不改变 handler / 权限 / 保存行为**。本轮只动 CSS 值与
`DESIGN.md`，没有改任何 TS 逻辑。

## 2. 禁用态：9 个值 → 1 个令牌

| 阶段 | 证据 |
|---|---|
| 收敛前（V-0 扫描） | 声明里写死的不透明度有 **9 个值**：0.25 / 0.3 / 0.35 / 0.4 / 0.42 / 0.45 / 0.5 / 0.55 / 0.6（另有 `cursor: default` 20 处 vs `not-allowed` 3 处） |
| 收敛后 | `tokens.css` 定义 `--ctl-disabled-opacity: 0.5`；**21 处** `:disabled` 全部引用它 |
| 实测（探针） | 21 个样本（11 个真实可见 + 10 个借用产品类名）计算 `opacity` 只有一个值 `0.5`，且等于令牌值 |

- **视觉变化（如实记录）**：`.tl-move`(0.25)、`.send`(0.3)、`.browser-nav`(0.35)、
  `.srow-menu-btn`/`.review-act`(0.4)、`.rp-tool-menu-item`(0.42)、`.rdiff-gap`(0.6) 向 0.5 靠拢
  —— 禁用感更一致，也更可辨。0.45 / 0.5 / 0.55 三档本来就分不出来，合并无感。
- **不套默认值的**：`.ub-item.dim`、`.tok.dim`、`.tl-dot.off`、`.trow-head .chev`、
  `.cborder-dash` —— 它们是「半失效 / 过期 / 装饰」，不是控件禁用。令牌注释里写明了。
- **未统一（记录为建议）**：`cursor` 仍是 `default`(20) 与 `not-allowed`(3) 混用。

## 3. 焦点环：4 种写法 → 1 个来源

| 令牌 | 值 | 用途 |
|---|---|---|
| `--focus-ring-color` | `var(--accent)` | 颜色（随主题变） |
| `--focus-ring-w` | 1px | 默认宽度 |
| `--focus-ring-offset` | 1px | 默认偏移 |
| `--focus-ring-w-strong` | 2px | 小目标 / 浮层里空间紧张时 |

- 原来的 4 种组合（`1px solid --accent` / `2px solid --accent` / `1px solid --accent-line` /
  `2px solid --accent-line`）**全部清零**，改为引用令牌；全局 `:focus-visible` 也改用令牌。
- 有意例外（不是遗漏）：结构性把手与输入框用 `outline: none` 加**自身**焦点视觉 ——
  `.resizer` / `.rp-vgrip` / `.browser-splitter`（`::after` 高亮）、`.grip` / `.rp-grip` /
  `.proj-group-act`（提亮）、`.composer textarea`（卡片 `focus-within` 环）、
  `.set-input`（边框变色）、`.term-grip`（背景提亮）。
- 真实键盘验证（`scripts/shot-controls.mjs`，主进程 `sendInputEvent` 真按 Tab）：
  普通控件 `0.8px solid` → ×1.25 zoom = **声明 1px**；`.rail-mode-btn` `1.6px` = **声明 2px（强调档）**；
  颜色随主题变化（dark `rgb(147,164,244)` / light `rgb(82,100,200)`）。
- 静态验证（探针）：样式表里 20 条含 `:focus-visible` 的规则，**没有任何一条**写死了
  焦点环颜色或宽度。

## 4. 命中区与对比度（测量记录）

| 控件 | 命中区 | 文字/图标对比度 |
|---|---|---|
| `.tb-icon` | 26.0 × 24.0 | 13.44:1 |
| `.wbtn` | 46.0 × 24.0 | 8.26:1 |
| `.rail-icon` | 26.0 × 26.0 | 5.50:1 |
| `.send` | 32.0 × 32.0 | 7.70:1 |
| `.rp-btn` | 61.4 × 24.4 | 8.26:1 |

判据：命中区 ≥ 24×24（WCAG 2.2 target size 下限，容差 0.5px 应对分数像素缩放）；
UI 文字/图标对比度 ≥ 3:1（WCAG「组件/大字」档）。全部达标。
配色令牌本身在深浅两主题下的对比度见 [L3 图标一节](../dev/HANDOFF.md)（fg 6.3–15:1）。

## 5. 密度三档仍有效

`--d-message-gap` 三档实测：`standard 32px` / `compact 16px` / `comfortable 48px`（互不相同）。
探针用 `data-density` 切档后读计算值，再恢复原值 —— 开关没有被这轮改动影响。
（`.msg` 随档位变化的那条断言在无 fixture 内容的窗口下如实跳过。）

## 7. 本片没做（如实列出）

- `cursor`（`default` vs `not-allowed`）未统一 —— 记录为建议，不影响可用性。
- 「危险」与「加载」态：V-0 扫描未发现同一意图的重复定义（危险色统一走 `--err`/`--err-soft`，
  加载态由各自状态类驱动），因此没有为凑改而重写。
- 菜单生命周期没有新写 overlay 管理器（沿用既有实现），符合 V-1 的约束。
- 未删任何旧 CSS 文件；未新增 `!important`（`motion.css` 既有 11 处未动）。
- 真机指标准入未跑（density/light/dialog 等既有场景未重跑）—— 本轮改动是纯令牌替换，
  已由 `controlstates` + `iconstate` 两个 cost 0 探针覆盖。

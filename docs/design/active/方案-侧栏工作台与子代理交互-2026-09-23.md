## 2. 信息架构与默认行为

| 区域 | 默认可见内容 | 打开后的内容 | 关闭语义 |
|---|---|---|---|
| 左侧项目栏 | 项目、默认预览数量的会话 | 更多会话、项目浮层菜单 | 收起仅重置“更多会话”，不停止会话 |
| 会话标题栏 | 标题、目标入口；有子代理时显示状态入口 | 目标浮层、子代理紧凑列表 | 关闭浮层不改变业务状态 |
| 右侧工作栏 | 无历史布局的新会话显示“开始”页 | 工具、审查、浏览器、文件、子代理详情 | 收起保留资源；关闭标签按资源类型处理 |

右栏开始页入口顺序：**审查、终端、浏览器、文件、工具**。终端只有 H-11 可用时出现为可执行入口；未接入时不放一个永久灰按钮，可以在工具能力说明中标注未接入。截图一致性不覆盖真实能力边界。

开始页顶部保留展开/恢复宽度、收起右栏；卡片组宽度 `min(360px, 可用宽度 - 32px)`，行高建议 44px、间距 6px。高窗口中位于内容区垂直中段偏上，矮窗口改为顶部 24px 留白并允许滚动，不用绝对定位把入口挤出屏幕。

“开始”和“工具”是不同页面：开始页只负责导航，工具页承载磁贴。开始页始终可返回；有已保存布局时优先恢复有效活动页，不强制覆盖用户上次阅读位置。关闭最后一个资源标签回到开始页；工具页和开始页是固定导航，不能误当网页资源释放。

首次打开右栏的默认展开规则沿用当前设置。收起右栏统一为整个工作栏不可见，包括浏览器原生区域；“隐藏标签栏但网页继续占整列”的旧语义不再用于收起按钮。扩大工作栏是单独动作，退出后恢复用户宽度。该变更必须在 H-3/H-9 同片核对 App 布局，不能只隐藏标签 DOM。

## 3. 左栏收起与项目菜单

### 3.1 更多会话

1. 监听左栏从展开到收起的**边沿事件**，不是每次渲染或每次重新挂载都重置。
2. 清空当前侧栏作用域的 `expanded-sessions`，再次展开按现有 `SESSION_PREVIEW` 显示；实施时读取常量，不另写一个数量。
3. 保留 `collapsed-projects`、项目排序/分组、分支展开、选中会话、滚动恢复策略；不要一并执行“全部折叠”。选中项超出预览时沿用现有可见性规则，不能顺带切会话。
4. 搜索词保留。搜索期间继续显示匹配结果；搜索临时展开不能写入用户展开偏好。清搜索后反映已重置的预览数量。
5. 收起同时关闭项目/分组/会话菜单。右栏收起、窗口失焦、模型继续输出都不触发该重置。

### 3.2 项目右键菜单

改用应用级 overlay root 的定位浮层，不成为 `.rail` 滚动列表的一部分。右键锚点取指针坐标；省略号、Shift+F10、Menu 键取项目行/按钮矩形。打开不改变当前项目，不折叠会话、不触发拖排序。

- 菜单宽度建议 224px，视口四周安全距 8px；水平翻转、垂直上翻，极矮窗口才在菜单内滚动。
- 菜单行建议 32px，分组间留分隔；复用已有项目动作和权限，不凭参考图新增删除、移动磁盘目录等功能。危险动作置末组，沿用现有确认链。
- 打开前记录来源元素；箭头移动焦点、Home/End、Enter 执行、Esc 关闭并归还焦点。禁用项有原因；外点关闭不吞掉用户对另一个控件的正常点击。
- 滚动锚点容器、关闭左栏、切项目、删除锚点时关闭；窗口 resize/缩放重算或关闭，不能留下脱离来源的菜单。
- 同一时间一个普通菜单。对话框优先；焦点返回目标已卸载时回到左栏开关。
- 菜单打开/关闭前后测量相邻项目行，位置与列表 scrollHeight 不改变（允许测量误差 ≤1 CSS px）。

## 4. 目标独立浮层与标题规范

### 4.1 外观与内容顺序

会话标题旁保留小型“目标 · 1/3”入口；无目标显示“目标”，点击解释当前为空并提供现有目标设置入口，不在查看时隐式创建目标。点击出现锚定浮层，建议宽 360px，最大 `min(420px, 100vw - 24px)`、最大高 `min(620px, 70vh)`；单一纵向滚动区，浮层头留在上方。

顺序：目标短标题与阶段 → 原始目标/达成判据（可展开原文）→ **任务清单**与完成数 → **产物** → **参考**。三个分区独立折叠，首开任务展开，产物/参考没有内容时显示“暂无产物/暂无参考”。阻塞原因紧跟阶段，不能埋进折叠区。自主模式的继续/停止等原有语义不变。

这里的“任务清单”取 **GoalState.steps**，不要把现有 `yan tasks apply` 的任务服务并入目标服务。现有任务面板（todo 分区）布局及所有权不变；本需求只授权独立目标展示。目标步骤和任务服务条目不得合并计数或双向写入。

### 4.2 可执行的长度规则

“标题长度”分语义短标题与像素布局两层处理，不能直接裁掉用户原文。

| 对象 | 短标题建议/上限（grapheme） | 展示规则 | 原文出口 |
|---|---|---|---|
| 会话标题 | 生成建议 ≤24，不改历史存储内容 | 单行省略；目标/子代理入口不被挤掉 | 聚焦/悬停完整文本、现有重命名 |
| 目标短标题、步骤短标题 | 建议 ≤20，显示上限 28 | 默认一行，不自动折叠分区 | 点击条目展开完整说明；键盘同等可达 |
| 子代理任务短标题 | 建议 ≤20，显示上限 28 | 列表第一行一行省略，活动第二行独立 | 详情首段完整 task |
| 文件/产物标签 | 不按字数修改路径 | 中间省略，保留扩展名 | 完整路径、来源与定位 |

采用 `Intl.Segmenter` 或项目统一等价函数按字素裁剪（emoji/组合字符不劈开）；像素层仍需 `min-width:0`、`minmax(0,1fr)` 与 ellipsis。28 字素不保证 28 个汉字在窄栏全显，因此真实宽度截断始终生效。tooltip 不是唯一原文入口。

短标题优先使用明确的可选 `displayTitle`；没有时从原 title/task 确定性派生，不为整理标题额外调用模型。若增加字段，由宿主归一化，旧记录兼容读取；输入任务、用户 brief 和完成判据始终原样保存。长标题不得触发目标块收起，不改变完成状态。

### 4.3 产物和参考的数据边界

当前 `GoalState.evidence` 是字符串，不等于结构化文件与引用。U-3a 首期只重用真实步骤和原文证据，产物/参考在无可靠绑定时显示空态，证据仍有“验证证据”出口，不丢失。

U-3b 再增加可选的结构化链接：`id / kind(file|url|text) / label / target? / sourceMessageId? / goalId`，宿主校验后按目标归属存储。文件点击走现有预览与权限检查；URL 沿用外链策略；纯文本证据不能猜成文件、不能冒充已存在产物。不复制文件内容或会话正文到布局存储。

## 5. 可移动工具磁贴

### 5.1 首期范围与发现方式

工具页沿用现有 `context / quota / todo / queue / files / ext / log / actions` ID，逐项按能力开放移动。首期支持上下文、额度、队列、日志、操作、现有扩展状态块；文件分区先作为“打开文件页”的入口，完整文件树留在文件页；todo 保持原布局、不浮动；目标与子代理走各自独立入口，不又登记成工具磁贴。

这里的 ext 仅展示当前既有状态，不新增或恢复 pi 插件。工具库升级为右栏工具页内的稳定面板，提供磁贴目录、位置标签及“拖动 / 浮动 / 放回工具页 / 收进库”按钮。既能从工具页拖出，也能从库拖出；保留键盘操作作为等价路径。

一个磁贴 ID 只有一个主实例：工具页、浮动层、工具库三选一。可在工具页保留“已浮动 · 定位”轻量占位，不能再挂载第二份订阅或按钮实例。空数据时显示真实空态，不抹掉用户放置的磁贴。

### 5.2 拖放状态机

`idle → pressed → dragging → commit / cancel`。按下标题把手后移动 ≥6 CSS px 才进入 dragging；正文选字、按钮与滚动都不开始拖动。拖动时使用 pointer capture 和单一 drag overlay，源容器保持占位。

| 目标 | 放开效果 |
|---|---|
| 工具页的前/后插入线 | 停靠并排序；复用同一排序纯函数 |
| 工具库收纳区 | 隐藏到库，仍能恢复 |
| 应用内容区域空闲位置 | 放置浮动磁贴，并吸附安全边缘 |
| 应用外、标题栏系统按钮、无效区域 | 回到原位置，不写入 |

Esc、pointercancel、失焦、切会话/项目、关闭源窗口均取消并释放捕获；外点关闭在 dragging 期间暂停，放开后的合成 click 不触发磁贴内部动作。屏幕外不丢失磁贴；窗口缩小/缩放后重新夹取边界。

浮动磁贴只在应用内容区域内移动，不生成 OS 窗口，不覆盖系统标题栏；初始宽度建议 300px，最窄 240px，最大 420px，窗口更窄则以可用宽度为准。磁贴头高建议 32px，默认内容最大高 `min(360px, 50vh)`；长内容内部滚动，拖把固定。最大化详细阅读应打开对应工具详情，不无限扩张悬浮卡。

### 5.3 布局、会话与持久化

- 一个版本化 ToolLayout 拥有位置真源，建议 `version:2, tiles:[{id, placement, order, rect?, collapsed}], revision`。这是提议契约，实施前与 H-3 owner 冻结实际字段。
- 用户布局偏好为应用级（与现有 toolOrder/toolHidden 一致）；**内容始终绑定当前会话**。切会话取消拖动并重新选择数据，不能显示上一个项目的队列/日志。每片都有项目/会话身份与失效检查。
- 旧 `toolOrder/toolHidden` 单次迁移成停靠/入库，默认没有浮动项；旧字段仅供读取迁移，迁移成功后只写新真源，不维护双向同步。迁移失败保持旧布局并有恢复入口，不删业务数据。
- 保存位置使用相对内容区的归一化坐标 + CSS 尺寸；只在 commit/调整结束后保存，不每帧写盘。保存带 revision 或串行最新写，防慢请求覆盖新拖动。
- 恢复时过滤未知 ID、去重、夹取越界值；新增工具按默认策略补入。恢复默认只重置布局，不清空任务、日志、上下文或产物。
- 持久化磁贴折叠偏好；菜单开关、拖动中状态、hover、临时遮挡只存在内存。

### 5.4 Electron 原生网页与遮挡

不能用 CSS z-index 解决 WebContentsView 遮挡。H-9 建立唯一显隐协调器，输入至少包括右栏可见、活动资源、当前会话、覆盖层阻塞集合。目标/菜单/拖动预览与浏览器相交时隐藏原生区域，资源仍运行。

浮动磁贴首期允许放在 DOM 内容区；网页矩形上持续放置浮动磁贴不支持：拖动途经网页时暂隐网页并显示放置边界，放开若与网页区域重叠则吸附到最近可用 DOM 区；若不存在能完整容纳磁贴的区域，则退回工具页，并说明原因。避免磁贴一放下就永久遮掉浏览器。

每个 overlay 领取独立 blocker token；关闭时只释放自己的 token。旧 SubagentPreview 清理函数“只要 browserOpen 就 setVisible(true)”必须移除，由协调器重新判定；多个弹层关闭顺序不能把原生网页提前露出。切会话后的旧 async 回调不恢复旧网页；bounds 换算继续乘 zoomFactor。

## 6. 子代理体验

### 6.1 三层展示

1. **入口**：会话标题旁，仅有本会话子代理时显示“子代理 3 · 运行中 1”；没有任务时从工具页的操作入口“新建子代理”发现功能。计数含 attached 和 detached，按 runId 去重。
2. **列表**：宽建议 380px（允许 340–420px 自适应），最大高 `min(520px, 65vh)`。第一行状态图形 + 短标题 + 用时；第二行最新活动/结果摘要；整条可开详情，右侧只留一个更多按钮。运行中在前，其余按结束时间倒序；用户键盘浏览时不要因排序更新跳焦点。
3. **详情**：右侧工作栏正式资源标签 `subagent:<runId>`，取代工具页底部的大块嵌入式转录。同一 runId 从标题菜单、回合短入口、通知打开都激活同一资源，不叠加副本。返回列表保留列表滚动。

列表默认筛选“全部”，可选“运行中 / 待审阅 / 已结束”；失败显示明确失败原因摘要，不能都画成停止。独立任务带“独立”小标，attached 带可回到父回合的来源入口。切换会话只显示该父会话/明确会话链的任务；无法确定归属的旧条目不猜测归属，放入单独历史入口并说明。

### 6.2 详情结构与动作

固定头：短标题、状态、关闭；元信息区：完整任务（可展开）、模型、目录、工作树/工具受限只读、来源回合、用量（有证据才显示）。正文三页签：**概览 / 过程 / 变更**。

- 运行时默认概览：最新活动、耗时、已有结果；可切过程。新输出不强制改页签、不抢焦点。
- 过程复用现有转录渲染；用户上滚停止跟随，新输出显示“回到最新”；列表不逐 token 改行高。
- 完成时概览给最终结果与变更摘要；没有结果则明示，不能把最后一段日志冒充结论。
- 变更沿用已有 diff、审阅和合并链；只读无变更不展示合并。合并冲突保留记录与工作树，清理/关闭界面不隐式 discard。

| 状态 | 主动作 | 次动作/限制 |
|---|---|---|
| starting / running | 查看过程 | 停止：pending 期间禁重复点击，失败可重试 |
| done + pending review | 查看变更 | 明确合并；保留现有审批语义，不自动合并 |
| done + 无变更 | 查看结果 | 收起/从列表隐藏 |
| error | 查看原因 | 复制原任务；首期不提供暗含新执行的“重试” |
| cancelled | 查看已有输出 | 不标为完成 |
| review conflict | 查看冲突 | 不把合并失败覆盖执行成功状态 |

“执行状态”与“审阅状态”是两个字段，不能用一个颜色代替。关闭详情、收起右栏、隐藏已结束条目都不停止任务；停止与丢弃变更单独操作。现有 clearSubagents 的具体删除语义必须核对后再接“隐藏已结束”，不能仅换按钮文字导致数据丢失。

启动表单放在子代理列表/工作栏内：完整任务输入、模型来源、隔离模式说明、开始按钮。默认沿用 worktree；非 Git 或工作树失败明确报错，不静默降级成可写原目录。启动期间禁重复提交，失败保留草稿；成功才清空。首期不做 follow-up、不改并发、不嵌套代理；只读明确是工具白名单，不是 OS 沙箱。

### 6.3 token 与耗时

H-10b 从事件按消息 ID 去重累计 usage，持久化在子代理记录中，不从截尾 transcript 求和。需定义 delta/final 替换规则、重放去重和记录版本；旧任务无完整统计显示 `—`。UI 可先交付并隐藏无来源的 tok 列。

计时使用 startedAt/endedAt 与现有 formatDuration，终止后冻结；父回合时长不因后台子代理继续运行而增长。多个代理 token 可在统计口径明确后求和，但并行墙钟耗时不能相加。父回合 usage 的完整聚合仍属于 H-6b，不顺带宣称已完成。

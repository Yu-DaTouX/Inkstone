# 砚 Android · UI 与功能设计方案

日期：2026-09-18。状态：**设计提案，尚未实现 Android UI 或 APK**。

## 1. 定位与依据

Android 是电脑端砚的随身工作入口：看进度、读结果、继续对话、处理需要关注的任务。模型、pi、工具执行、项目文件和供应商凭证留在电脑上。电脑离线时只能阅读已缓存内容与保存草稿。

依据：当前 [HANDOFF](../../dev/HANDOFF.md)、[远程协议](../../dev/REMOTE-CONTROL.md)、[DESIGN](../DESIGN.md)、[实际样式令牌](../../../src/renderer/src/styles/tokens.css)、[主界面实测截图](../preview/matrix-main-1440x900-100-dark-2026-09-17.png)，并核对了 [远程服务](../../../src/main/remote-server.ts) 和 [主进程接入](../../../src/main/index.ts)。截图是已有桌面证据，本方案没有启动新窗口或做 Android 运行验证。

DESIGN 部分早期章节的三栏尺寸、偏蓝灰配色和圆角，与当前 tokens.css / 实测图存在差异。本提案取当前中性灰、小圆角的视觉结果为参考；实施移动令牌前必须回填 DESIGN 的移动端章节，不能把本提案变成第二份令牌真源。本次不调整桌面令牌。

核心体验：打开手机能知道电脑是否可用、哪个会话在运行、最新结果是什么，以及自己还能做什么。

## 2. 延续什么，调整什么

| 项目 | 桌面现状 | 安卓提案 |
|---|---|---|
| 视觉语言 | 中性灰底、等宽、小圆角、细边框 | 保留；不增加大面积渐变、浮雕投影、聊天头像装饰 |
| 内容组织 | 会话栏、消息流、工具栏 | 手机单栏逐级进入；宽屏再展开列表与正文 |
| 字体 | Maple Mono CN，正文 12.5px | 延续字体身份；正文建议 16sp，不能直接缩放桌面字号 |
| 用户消息 | 灰底内容块与细强调边 | 保留宽内容块，避免窄小的左右气泡浪费代码宽度 |
| 推理 | 默认展开、限高、展示最新片段 | 同样默认展开，建议上限 min(可用内容高度的 32%, 220dp)，顶部渐隐，提供展开全部；没有独立纵向滚动条 |
| 工具 | 过程摘要与可展开详情 | 运行中的工具显示短摘要，已完成组收成一行，详情打开独立页面 |
| 状态 | 符号、文字、语义色 | 三者保留，不依赖颜色区分成功/失败 |
| 鼠标交互 | hover、拖拽、右键 | 点击、可见的更多菜单；长按仅作快捷入口 |

移动端拟定尺寸：页面边距 16dp，内容间距 8/12/16/24dp；顶栏 56dp；底部导航约 64dp（另加系统安全区）；列表最小 72dp，随字号增长；可点击目标至少 48×48dp；图标本体 20–24dp。正文 16sp / 约 26sp 行高，标签 14sp，次级信息 12sp，标题 18sp，代码 13–14sp。正文随系统字号缩放，不以固定高度裁字。

圆角候选：标签 4dp、卡片 6dp、输入框 8dp、底部面板 12dp。保留桌面克制感，组件可以扩大触控范围而不扩大装饰。

配色引用当前实际令牌：深色主背景 #0a0a0a、面板 #171717、输入/浮层 #262626、正文 #fafafa、次要文字 #a1a1a1、交互蓝 #4c7ef3；浅色主背景 #ffffff、面板 #fafafa、正文 #0a0a0a、交互蓝 #2563eb。颜色还须按实际字号与背景验对比度；深浅主题同时设计，默认跟随系统。模型推理保留原文，不增加语言强制规则。

## 3. 信息架构

一级导航只有三个：**会话 / 设备 / 设置**。默认进入上次设备的会话列表。对话页隐藏一级底部导航，把底部空间交给输入框。

```text
会话
 ├─ 当前电脑切换、连接状态、搜索、全部/运行中筛选
 ├─ 新对话
 └─ 对话
     ├─ 消息、推理、工具组、输入框
     ├─ 工具详情（完整输出、复制、搜索）
     └─ 会话详情（任务、上下文、运行信息；文件后续加入）
设备
 ├─ 电脑列表、最近连接、连接诊断
 └─ 添加电脑（开发版手动地址；正式版配对）
设置
 └─ 主题、字号、通知偏好、缓存、版本与隐私
```

不把“任务”做成新的独立产品：会话详情里的任务清单仍来自现有扩展，不建立移动端任务数据库。设备代表电脑连接，本地档案不显示“已登录/已同步”。

## 4. 关键页面

### 4.1 会话首页

顶栏“砚”，右侧新建按钮；下一行显示电脑名与连接状态，可点击切换设备。列表上方搜索与筛选，运行中的会话可集中查看，但不随事件不断重新排序正在阅读的列表。

每条会话：标题（最多两行）、项目展示名、最近更新时间、状态图标与文字；有可靠数据时显示末条摘要。未知任务状态显示“状态待更新”，不能从无事件推断“已完成”。项目仅作已有摘要分组，不承诺首版能够创建或管理电脑项目。

搜索首版只搜索已加载的标题与项目名，明确显示搜索范围；全文检索需要新接口。无会话时给“新建对话”；无搜索结果提供清空搜索。离线时保留缓存列表，顶部显示“电脑未连接 · 上次更新 …”。

```text
┌──────────────────────────────┐
│ 砚                      ＋   │
│ 工作电脑 ▾        ● 已连接   │
│ 搜索会话…                    │
│ 全部    运行中               │
│                              │
│ ▌安卓界面规划                │
│  pi-desktop · 正在运行 · 现在 │
│                              │
│  调整工具详情                │
│  pi-desktop · 已结束 · 12分前 │
│                              │
│  会话        设备      设置  │
└──────────────────────────────┘
```

### 4.2 对话页：核心工作面

顶栏：返回、会话标题、详情入口。第二行显示设备/项目与当前运行状态，窄屏省略中间文字，完整信息放详情。模型信息有真实来源才显示；首版不提供无接口支撑的模型选择器。

消息流采用桌面相同的“你 / 砚 + 内容块”结构。用户内容弱灰底，助手正文直接铺在主背景上。推理、工具组、正文顺序保持一致。超宽代码与表格可横向滚动，代码提供“换行显示”开关；全文可选中复制。

底部输入框默认 2 行、最多约 6 行，再通过全屏编辑入口输入长内容。软键盘回车换行，发送由明确按钮完成。键盘弹出时输入框保持可见，尊重系统输入法和手势区域。滚动到旧消息时不被新 token 拉回底部，显示“有新内容 ↓”；点击才回到底部。

```text
┌──────────────────────────────┐
│ ‹  安卓界面规划         详情 │
│ 工作电脑 · pi-desktop        │
│                              │
│ › 你                         │
│ ┌──────────────────────────┐ │
│ │ 根据当前风格设计安卓界面 │ │
│ └──────────────────────────┘ │
│ ✧ 砚                         │
│ │ 正在推理 · 8秒             │
│ │ …保留细边框和等宽字体     │
│ │               展开全部    │
│ ▸ 已调用 2 次工具            │
│ 建议采用单栏会话工作流…      │
│                              │
│ 正在运行          停止任务   │
│ ┌──────────────────────────┐ │
│ │ 继续补充你的想法…        │ │
│ │                  发送 ↑  │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

上图“停止任务”是目标设计，需要定向停止接口后才能开放。首版文本输入不摆放不可用的相机/文件按钮。运行中仍可编辑草稿；排队与插入语义未定前，发送按钮禁用并说明“本轮结束后可发送”，不能擅自映射桌面队列。

### 4.3 会话详情

从对话页打开全高页面：任务、上下文、运行信息分区按需展开。任务只读呈现扩展提供的状态；上下文只显示有来源的使用量、预算和更新时间，无数据时显示“暂不可用”。不根据字符数伪造 token 占比，也不显示虚假费用。

更多菜单首版只放重命名、复制会话标识；删除、分支、归档必须有对应接口后再加入。上下文压缩、Deep Context 与策略开关后续接入，不能借手机设置偷偷修改电脑配置。

### 4.4 工具详情

独立页面：工具名、运行状态、耗时、输入、输出。完整输出垂直滚动，不在消息流里套长日志的纵向滚动框；长行横向滚动。提供复制输出与页内查找。若服务端截断，显示“输出不完整”，不能把截断尾部当作命令结束。

### 4.5 设备与连接

开发版：添加电脑 → 地址/端口/token → 测试连接 → 显示协议与能力 → 保存设备。提示电脑端服务需要开启；凭证默认隐藏，不进入截图式诊断分享内容。

正式版目标：电脑开启远程访问 → 显示短时配对码/二维码 → 手机扫码或手输 → 双端确认电脑身份与设备名 → 授予可撤销权限。二维码、设备密钥、权限分级、受保护传输均待开发，不能只给现有明文 token 套扫码外观就宣称完成配对。

连接状态分别为：未配置、连接中、在线、重连中、电脑不可达、认证失效、协议不兼容。不能把网络超时直接叫“电脑关机”。“断开连接”只断开手机订阅，文案说明电脑任务会继续运行。

### 4.6 设置

本机设置：系统/深/浅主题、正文大小、缓存大小与清除缓存、应用版本、设备凭证管理。清除缓存不删除电脑会话；删除设备只移除本机连接，正式版另提供撤销授权。

通知开关按能力呈现：只有真实后台通知链路接通后才提供“后台完成提醒”；开发版写清“仅应用打开时更新”。锁屏内容默认隐藏消息正文。手机退出不代表电脑任务停止。

## 5. 必须设计完整的交互状态

| 场景 | 界面与行为 |
|---|---|
| 查看另一个会话 | 只读取历史，不调用 select，不抢走电脑当前界面 |
| v1 向另一会话发消息 | 明确提示现有接口会同时切换电脑当前会话；发送前固定目标 ID；正式版改为独立定向发送 |
| 发出请求后网络中断 | 显示“发送结果待确认”，保留内容；不自动重发，避免重复执行工具 |
| 服务器明确拒绝 | 展示原因并允许编辑重试；失败气泡不会伪装成已发送 |
| SSE 断线 | 标记数据可能过期；恢复后取快照和当前历史，再继续流式显示 |
| 桌面切换/删除会话 | 手机当前阅读目标保持固定；被删则显示说明与返回入口，不将草稿投递到别的会话 |
| 切设备 | 缓存、草稿、运行状态按设备 ID + 会话 ID 隔离 |
| 手机进入后台/进程被回收 | 保存草稿与阅读位置；返回前台重新鉴权并刷新，不假定 SSE 始终在线 |
| 停止任务 | 定向接口支持后，对明确的任务 ID 发停止，先显示“停止中”，收到终态才显示“已停止” |
| 需要用户回答/授权 | 目前远程流不转发桌面模态请求；只有新增结构化事件后才能显示可回答卡片，否则不承诺手机处理 |
| 返回手势 | 先关闭输入法/浮层，再返回上一页；不丢草稿，不停止任务 |

消息状态区分“发送中 / 已接收 / 结果待确认 / 明确失败”；服务端接收成功不等于模型已经完成。请求幂等与回执查询到位前，结果待确认只能先刷新核对，不设置自动重试按钮。

## 6. 功能范围与协议依赖

“已有 API”只表示源码提供路由，不代表 Android 已完成或完整生产可用。

| 能力 | 当前基础 | 安卓计划 |
|---|---|---|
| 连接与协议识别 | health / info / status | 第一阶段，区分认证失败与不可达 |
| 会话列表 | sessions，当前快照最多列 200 个 | 第一阶段，只承诺已加载范围；全量分页需新增 |
| 历史阅读 | 会话历史默认 200 条，上限 500，无翻页游标 | 第一阶段展示有限历史；超限提示；完整历史阅读需游标分页 |
| 实时消息/工具 | SSE 转发白名单通道 | 第一阶段做会话归属验证、补快照与重复事件处理 |
| 新会话 | new，以电脑 settings.cwd 决定作用域 | 第一阶段清楚显示作用域限制；指定项目需新增协议 |
| 文本发送 | messages，最多 20,000 字符且请求体最多 64KB | 第一阶段有限使用；字数与 UTF-8 请求体都校验，以服务端为准 |
| 重命名 | rename，最多 200 字符 | 第一阶段；失败后回读核对，避免部分写入后界面误报 |
| 停止任务 | abort，无目标 ID，操作当前 ac() | 定向停止补齐前隐藏手机停止操作；先查状态再停止不能消除竞态 |
| 任务/上下文概览 | todos/stats/state 等事件，非完整详情契约 | 有数据才展示；首次快照、归属和单位须补明确 |
| 排队/插入/撤回 | queue 事件，不等于写入接口 | 第二阶段，补定向队列命令与结果回执 |
| 提问与权限响应 | 桌面模态不转发 | 第二阶段新增 requestId、有效期、权限及响应路由 |
| 项目文件与 @ 引用 | 无远程文件接口 | 第二阶段：受控文件标识、预览/引用分离，不接受任意绝对路径 |
| 图片/附件 | 当前发送为纯文本 | 第二阶段新增大小限制、上传和生命周期 |
| 电脑模型与上下文设置 | 无远程设置接口 | 第二阶段，使用能力声明与服务端验证 |
| 后台可靠通知 | 无推送服务 | 后续独立工程项，不依赖后台永久 SSE |
| 外网/配对/撤销设备 | 未实现 | 正式分发前的产品门槛 |
| 浏览器/桌面操作 | 当前协议不提供 | 不纳入初版，不把手机工具详情做成任意 shell 入口 |

第一阶段展示项目名须来自服务端展示字段；不会把 Android 的文件路径当作电脑路径。记忆模块、get_tree、虚假账号同步不加入移动路线。

## 7. 先补协议，再完善交互

1. **目标身份**：每条状态/消息事件有稳定 deviceId、sessionId、runnerId，运行命令有 runId。当前事件只可选带 runtime，不满足时不能按“当前页面”猜归属。
2. **定向写入**：发送与停止在服务端绑定目标，执行时核验实例与会话版本；不得在 await 之后重新取可能已变化的全局 active controller。电脑视图选择与远程阅读/发送逐步解耦。
3. **回执与幂等**：clientRequestId、可查询接收结果；重连不会重发已经接受的消息。新建会话需返回稳定身份，即使会话尚未首次落盘。
4. **一致性恢复**：事件序列、快照水位和会话 revision；目标是先缓冲订阅，再按快照水位应用较新事件。当前 SSE 没有事件 id/重放，开发版只能补快照/历史并显式保留过期状态，不能声称无损续传。
5. **完整数据**：会话与历史游标分页、详情初始快照、工具输出截断标识。当前 history 还只在最近 500 个会话中查找，不能承诺任意老会话可访问。
6. **权限与传输**：设备配对、撤销、只读/可控制权限、受保护传输、响应脱敏；按现有主进程边界实现，不开放通用 Electron 调用。

## 8. 手机、平板与可访问性

以窗口实际可用宽度为准：<600dp 单栏；600–839dp 默认单栏，可按正文最小宽度决定是否展开列表；≥840dp 使用约 280dp 会话列表 + 剩余消息区，详情仍按需打开。以上为产品候选断点，分屏、横屏、折叠态都应重新计算，不能仅按设备型号分类。

交互区至少 48dp，点击目标不重叠。TalkBack 读出图标用途与任务状态；流式 token 不逐字打断朗读，阶段变更提供简短提示。大字体时标题、列表行、按钮可增高；200% 字号下仍能发送和返回。减少动态效果设置下关闭扫光，保留静态状态文字。

Android 的窗口适配、触控尺寸和后台限制参考官方文档：[不同显示尺寸](https://developer.android.com/develop/adaptive-apps/guides/support-different-display-sizes)、[触控与可访问性](https://developer.android.com/guide/topics/ui/accessibility/views/apps-views)、[后台任务概览](https://developer.android.com/develop/background-work/background-tasks)。因此本方案使用窗口适配和可恢复前台连接，不承诺后台常驻连接。这里没有锁定 SDK 或 UI 框架版本，实施前再验证。

## 9. 开发顺序与验收

### A. 页面设计与交互原型

交付会话列表、对话、详情、工具输出、设备连接、设置六种页面；深浅主题；空态、运行中、离线、发送未确认、长推理、大字体状态。原型必须注明模拟数据。此阶段不算 Android 工程完成。

### B. 内部前台客户端

实现手动连接、能力识别、有限历史、实时流、草稿、受限的新建/发送与重命名。协议归属不明时不开放控制，停止操作等定向接口。验收电脑和手机同时切会话、断网发生在发送响应前、电脑重启、中文输入法、长日志和进程回收。

### C. 完整远程管理

先完成定向命令、幂等与历史分页，再接入任务响应、队列、文件和设置。电脑与手机必须看到一致事实，手机状态不靠乐观推断覆盖电脑终态。

### D. 正式分发

# Inkstone 设计规范 v0.4

[文档索引](README.md) · [品牌规范](BRAND.md) · [代码地图](CODE_MAP.md)

本文是砚（Inkstone）界面的**唯一公开设计规范**：设计意图、令牌、控件、版面、信息层级、动效、安装与引导界面，以及以后升级规范的流程。实现以源码为准，本文说明「为什么这样、以后怎么改」。

下一版（终端风格、动效体系与「砚线」图标）的草案与路线见[界面重构计划](UI_REDESIGN.md)；其中的决定采纳前，以本文为准。

| 实现位置 | 内容 |
| --- | --- |
| `src/renderer/src/styles/tokens.css` | 颜色、字号、间距、圆角、控件尺寸、字重、投影、时长 |
| `src/renderer/src/styles/ui.css` | 统一控件的唯一外观：按钮、分段、开关、徽标、空状态、分区标题、键位 |
| `src/renderer/src/components/ui/` | 同一套控件的 React 组件（`Button` / `IconButton` / `Segmented` / `Badge` / `EmptyState` / `SectionTitle`） |
| `src/renderer/src/styles/motion.css` | 全部关键帧与动效令牌 |
| `scripts/design/icons/catalog.json` | 图标语义真源（`npm run icons` 生成） |
| `scripts/build-installer-sidebar.mjs` | 安装器侧栏与页眉位图 |

## 1. 设计意图

砚是**墨色工作空间**：安静、清楚、克制。对话与成果是主角，输入区是下一步操作的锚点，执行过程、用量和诊断从摘要到详情分层展开。

四条原则：

1. **内容优先。** 正文、产出和输入高于工具元数据；元数据默认淡显，悬停、聚焦或展开时才完整出现。
2. **一种意图一种长相。** 同一个意图（主要操作、次要操作、互斥选项、状态标签）在所有页面只有一种外观，由 `ui.css` 统一提供。
3. **克制层级。** 用背景色阶、留白和细分隔线表达层级；不用重复徽章、装饰渐变或持续发光争夺注意力。
4. **单一强调。** 靛蓝只表达选中、主要操作、链接和键盘焦点；成功、警告、错误保留独立语义色，品牌色不承担状态。

## 2. 令牌

### 2.1 颜色

深浅两套主题定义同名令牌（`html[data-theme]`），组件只引用令牌，不写色值。

| 令牌 | 用途 |
| --- | --- |
| `--bg-0` | 窗口底、中栏、分段容器底、设置内容区 |
| `--bg-1` | 左栏、右栏、会话头、卡片、弹层 |
| `--bg-2` | 次要按钮、输入框、用户消息气泡 |
| `--bg-3` | 悬停、分段选中项、导航选中项 |
| `--bg-4` | 按下、滚动条 |
| `--border-soft` / `--border` / `--border-str` | 分隔线 / 控件描边 / 悬停描边（半透明，适配任何底色） |
| `--fg` / `--fg-dim` / `--fg-mute` | 正文 / 次要（分区标题、说明） / 三级（元数据、诊断） |
| `--accent` · `--accent-soft` · `--accent-line` | 强调实色 / 浅底 / 描边 |
| `--on-accent` | 强调实底上的文字 |
| `--ok` `--warn` `--err`（各带 `-soft`） | 成功与新增 / 警告与待确认 / 失败与删除 |

规则：

- 绿色只表达成功或新增，不用来装饰「好的数字」；用量、缓存率等诊断值用 `--fg-mute` / `--fg-dim`。
- 新增颜色前先确认文本对比度 ≥ 4.5:1，并同时给出深浅两套值。
- 已删除的旧名（`--fg-0…4`、`--line`、`--line-1`、`--border-strong`）不再使用；`npm run check:motion` 会报告未定义的令牌引用。

### 2.2 字体与字号

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--font-ui` / `--font-body` | Segoe UI + 微软雅黑 UI | 界面、正文 |
| `--font-code` | Maple Mono CN（随包内嵌） | 代码、diff、终端、路径、键位 |
| `--fs-xs` 11 · `--fs-sm` 12 · `--fs-code` 12.5 · `--fs-base` 13 · `--fs-body` 14 · `--fs-lg` 15 | | |
| 页标题 | 18px / `--fw-strong` | 设置页标题、引导标题 |

字重只用三档：`--fw-regular` 400、`--fw-medium` 500（按钮、行标题、选中项）、`--fw-strong` 600（分区标题、页标题）。不写裸数字字重。

### 2.3 间距、圆角、尺寸

- 间距 4 的倍数：`--sp-1…6` = 4 / 8 / 12 / 16 / 24 / 32。
- 圆角：`--r-xs` 4（分段内的项、行内代码、徽标） · `--r-sm` 6（按钮、输入框、分段容器、导航项） · `--r-md` 8（菜单、消息气泡） · `--r-lg`/`--r-xl` 12（卡片、对话框、输入区容器）。
- 全圆角（`--r-full`）只给滚动条、进度条、开关、头像、计数点和悬浮圆按钮；按钮与分段不用胶囊形。
- 控件高度三档：`--ctl-h-sm` 24 · `--ctl-h` 28（默认） · `--ctl-h-lg` 32。按钮、分段、输入框只用这三档。

### 2.4 投影

界面内部的层级靠色阶，不靠投影。唯一的投影是弹出层（对话框、设置、引导、菜单）的 `--shadow-pop`，它表达「浮在内容之上」。

## 3. 控件

外观全部来自 `styles/ui.css`。模块 CSS 只写控件在自己版面里的**位置**（`margin`、`flex`、`align-self`、宽度），不重写底色、描边、字号、高度或悬停色。

### 3.1 按钮

| 写法 | 组件 | 用途 |
| --- | --- | --- |
| `.btn` | `<Button>` | 次要操作（默认）：对话框的取消、卡片操作、设置行操作 |
| `.btn.primary` | `variant="primary"` | 一个区域里唯一的主要操作（开始使用、提交、打开） |
| `.btn.ghost` | `variant="ghost"` | 行内低频操作、取消暂存、「不管了」 |
| `.btn.danger` | `variant="danger"` | 删除、移除、覆盖 |
| `.btn.icon` | `<IconButton label=…>` | 只有图标的按钮；必须给 `label`（用作 title 与无障碍名称） |
| `.btn.sm` / `.btn.lg` | `size` | 24 / 32px；默认 28px |
| `.btn.on` / `aria-pressed="true"` | `active` | 切换按钮的「已开启」 |

一个区域最多一个主要按钮。按钮文字写动作（「打开」「提交」），不写「确定」。图标在文字前；导航去别处的按钮可在文字后放 `chevron-right`。

### 3.2 分段控件

`.seg` > `.seg-btn`（`.sel` 或 `aria-pressed`），组件 `<Segmented>`。二到五个互斥选项：主题、语言、视图切换、筛选、档位。选中项用 `--bg-3` 底 + 正文色 + 中等字重，图标变强调色；**不用强调色实底**。`.seg.sm` 用于面板内部与筛选。

同一外观的变体：会话头视图切换（`.shead-view`）、右栏队列模式（`.rp-switch`）、模型菜单档位条（`.mt-stops`）。新增互斥选项时直接用 `.seg`，不再新建变体。

### 3.3 其他

- **开关** `.switch-pill`（带 `.on`）：布尔设置；开启为强调色实底。
- **徽标** `.ui-badge`（`accent` / `ok` / `warn` / `err`）：状态标签与计数。浅底 + 同色描边 + 同色文字，不用实底。
- **空状态** `.ui-empty` / `<EmptyState>`：一句事实 + 可选的下一步操作。不画插图，不写「暂无数据」式空话；「没有改动」与「不在 Git 仓库里」这类不同事实用不同文案。
- **分区标题** `.ui-section-title` / `<SectionTitle>`：12px / 600 / `--fg-dim`，图标 `--fg-mute`。
- **键位** `.ui-kbd`：只给真正接了快捷键的动作画键位。

### 3.4 图标

Lucide 描边图标，语义名 → 图标写在 `scripts/design/icons/catalog.json`，一个图标只承担一个语义；尺寸只用 12 / 14 / 16。界面里不用 `✓ ○ ◐ ✕` 这类文字符号当图标（状态点用 CSS 画）。改图标：改编目 → `npm run icons` → `npm run check:icons`。

## 4. 版面与信息层级

```
┌ 标题栏：左栏开关 · 品牌（只此一处） ······ 固定 · 浏览器 · 右栏开关 · 窗口控制 ┐
├ 左栏 ┬ 会话头：标题 · 视图切换 · 项目胶囊 · 目标 ───────────┬ 右栏（检查器）┤
│ 新对话 + 搜索 │ 对话流（内容列上限 --w-stream）                  │ 任务          │
│ 置顶 / 最近    │                                                    │ 上下文 · 额度 │
│ 项目 → 会话    │ 输入区（运行状态嵌在顶边） · 用量条（诊断，淡显）   │ 文件 · 队列   │
└ 待我处理 · 用户 ┴────────────────────────────────────────────────┴──────────────┘
```

- **品牌只出现一次**（标题栏）。左栏顶部是「新对话 + 搜索」。
- **右栏是检查器，不是仪表盘。** 分区之间只有一条细分隔线，标题 12px 半粗，右侧可放摘要（环形 + 数字）。分区可拖动排序、折叠或浮出为磁贴。
- **运行状态的主位置是输入区顶边**（spinner + 一句状态文字）。思考档位色只留在边线和 spinner 上，文字用 `--fg-dim`。工具行和任务列表只标自己的状态，不重复播报整体进度。
- **诊断信息常驻但退后**：输入区下方的用量条用 `--fg-mute`；需要细节时展开或悬停。
- **消息元数据按需出现**：用户消息不再有「你」标签（右对齐气泡即身份），时间与「分支」合并在气泡下方一行，平时 55% 不透明度，悬停或聚焦时完全显现。回合页脚（步数、用时、时间）只在回合末出现一次。
- **编码与日常共用同一骨架**：差异体现在默认展示的内容（编码突出改动、终端、文件；日常突出资料、成果、学习），不是另一套界面。
- 空入口不渲染：没有归档项目时不显示「已归档项目 · 0」；计数为 0 的筛选档不画。
- 窄窗口（900×520、940×620）下所有标题、按钮和筛选不能换成竖排或溢出；grid 弹性列一律 `minmax(0, 1fr)`（`npm run lint:css` 检查）。

## 5. 弹出层：设置、对话框、引导

- 遮罩：深色 `rgba(0,0,0,.5)`、浅色 `rgba(20,20,18,.28)`，2px 模糊。
- 面板：`--r-xl`，`--border` 描边，`--shadow-pop`。
- **设置**：左导航 `--bg-1`，内容区 `--bg-0`（深浅主题层级方向一致）。导航项 32px 高，选中为 `--bg-3` 底 + 强调色图标，不画框。内容区顶部有 18px 页标题；设置行是「标签 + 说明｜控件」两列，行之间一条细线，行本身不响应悬停（它不可点击）。打开时焦点落在当前页的导航项上。
- **首次引导**：清单而不是向导。每项是「状态标记（完成为绿色浅底圆 + 对勾；待办为警告色空心环）· 标题 + 说明 · 操作」，操作按钮并排、可换行，主操作只有一个。
- Esc 只关闭最上层；焦点圈定只在最上层生效；关闭后焦点回到打开它的元素。

## 6. 动效

关键帧只在 `styles/motion.css` 定义（`npm run check:motion` 拦截模块里的 `@keyframes`、裸时长和裸曲线）。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--mo-fast` | 110ms | 菜单、退场、按压 |
| `--mo-base` | 170ms | 浮层入场、列表项落位、tab 内容淡入 |
| `--mo-slow` | 240ms | 对话框、设置、引导入场 |
| `--mo-ease` | `cubic-bezier(.22,1,.36,1)` | 入场：快进慢停 |
| `--mo-ease-out` | `cubic-bezier(.4,0,1,1)` | 退场：干脆 |
| `--dur` / `--ease` | 120ms / 标准曲线 | 悬停、颜色、边框过渡 |

规则：

- 入场与退场成对（`usePresence` 延迟卸载），退场更快、位移更小。
- 位移不超过 6px，缩放不小于 0.965；不做弹跳或弹性动画。
- 按钮、分段、图标按钮按下时有 `mo-press` 反馈。
- 循环动画只挂在**真实运行**的状态上（spinner、输入区扫光、运行中的工具行），结束立即停止，且不能是唯一的状态信息。
- 主题切换是唯一的整屏动效（View Transition，圆心为触发按钮）。
- `prefers-reduced-motion: reduce` 下时长压到 1ms（保留终态，不删除动画，以免延迟卸载出现空窗）。

## 8. 可访问性与键盘

- 所有控件可 Tab 到达；全局 `:focus-visible` 为 1px 强调色环，小目标用 2px（`--focus-ring-w-strong`）。
- 禁用统一 `--ctl-disabled-opacity`（0.5）；更低的透明度只表示「过期 / 半失效」。
- 图标按钮必须有无障碍名称；分段项用 `aria-pressed`，tab 用 `role="tab"` + `aria-selected`。
- 元数据淡显不能让信息只在悬停时可得：聚焦同样让它完全显现。

## 9. 升级规范的流程

1. **先改规范再改代码。** 新令牌或控件变体先在本文写清用途与边界，再改 `tokens.css` / `ui.css`。
2. **新增控件先问能否复用。** 能用 `.btn` / `.seg` / `.ui-badge` / `.ui-empty` 表达的，不新建类；需要新变体时加在 `ui.css`，并补到第 3 节。
3. **模块 CSS 只管版面。** 发现模块里重写控件外观时，改成 `className="btn …"` 或组件，再删掉旧规则。
4. **检查。** `npm run typecheck`（含 CSS 布局检查）→ `npm run check:motion` → `npm run check:icons` → `npm run measure:css` 更新 CSS 清单 → 视觉矩阵截图（深浅主题 × 1440×900 / 940×620 / 900×520）核对。视觉结论以截图为准。
5. **记录取舍。** 推翻本文某条规则时，在对应章节写明新规则与理由；不保留两套并行的说法。

### v0.4 变更摘要（2026-09-28）

- 新增统一控件层（`ui.css` + `components/ui`）；设置里原本没有样式的 `set-btn`、工作台 / 审查 / 引导 / 收件箱的十余种按钮与分段写法并入统一控件。
- 右栏由卡片仪表盘改为检查器；会话头视图切换、队列模式、模型档位条改为统一分段外观。
- 品牌只保留在标题栏；左栏顶部改为「新对话 + 搜索」；无归档项目时隐藏归档入口。
- 用户消息去掉「你」标签，时间与分支合并为气泡下方的淡显行；运行状态文字改为中性色；用量条降为三级色。
- 设置增加页标题与新的层级；首次引导重排并移入 `settings.css`；安装器位图改为与应用同源的配色。
- 修复多处引用未定义令牌（`--fg-0…4`、`--line-1` 等）导致的静默失效样式；清理左栏工作区拨杆等无引用的旧样式与重复关键帧。

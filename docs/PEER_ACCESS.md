# 砚互联：两台电脑之间的访问与传送

两台都在运行 Inkstone 的电脑可以互相连接：一台按需查看另一台开放的会话与成果，把选定内容复制成本机副本，或在授权范围内向对方会话发消息。两台电脑可以属于不同的人。

## 前提

- 两台电脑网络互通。推荐同一个 Tailscale 网络；也可以用局域网地址，或自行建立的 SSH 端口转发。
- 被连接的一方在「设置 → 手机接入」里开启「允许手机接入」。砚互联和手机共用这个监听服务，但授权规则不同，见下文。

## 连接步骤

1. **被连接方**：打开「设置 → 手机接入」，点「生成配对码」，把地址和 6 位配对码告诉对方。
2. **连接方**：打开「设置 → 砚互联」，在「连接其他砚」里填入地址和配对码，点「配对」。配对只建立身份，不开放任何内容。
3. **连接方**：勾选想申请的操作（查看 / 复制 / 发消息），可以附一句说明，然后点「申请连接」。
4. **被连接方**：会弹出审批窗口。勾选要开放的项目（默认一个都不选）和允许的操作（只能在对方申请的范围内收窄），点「批准本次连接」。两分钟内没处理，按拒绝处理。
5. **连接方**：连接建立后，点「浏览开放内容」，查看会话、复制到本机，或导入项目记忆。

## 授权规则

| 规则 | 说明 |
| --- | --- |
| 只在本次连接有效 | 授权只存在内存里，绑定连接方保持的事件流。事件流一断（网络中断、任一方结束、砚退出）立即失效，重连必须重新申请、重新批准，不会静默续用。 |
| 按项目与操作限定 | 每个请求都会核对：连接是否有效、项目是否开放、操作类别是否允许。超出范围的请求直接拒绝，要扩大范围只能重新申请。 |
| 随时撤销 | 被连接方可以在「设置 → 砚互联 → 这台电脑被连接」里撤销某次连接，或在「手机接入」里撤销设备；撤销后立即生效。 |
| 不开放的内容 | 模型凭证、SSH 私钥、个人记忆不在开放范围内。敏感确认（删除、授权、付费等）只能在被连接的电脑本机处理。 |
| 与手机的区别 | 手机被视为你自己的设备，配对后即可访问全部会话；砚互联的设备在配对后什么也访问不到，每次连接都要批准。 |

## 查看与复制

- **查看**：读取对方开放项目里的会话（最近 50 条消息）和成果，本机不保留副本。
- **复制到本机**：在本机数据目录的 `peer-imports/` 下生成一份副本，包含消息、能取到的成果文件，以及来源电脑、项目、原会话 id、导出时间。源文件已丢失或超过 10MB 的成果会标为未能复制，不会假装已经传输。副本不同步更新，也不迁移正在运行的任务。
- **导入项目记忆**：把对方项目中已确认的记忆导入到本机你选定的项目，成为**候选**。候选带 `peer:<电脑名>` 标签，并记录来源电脑、条目 id 和版本，需要你在「设置 → 项目知识」里确认后才生效。
- **发消息 / 中止任务**：需要 `send` 授权。消息在对方电脑上执行，只能发到开放项目里的会话。

## 当前限制

- 连接方需要保持砚运行，连接才会持续；被连接方的砚退出后，连接随之结束。
- 断线后不会自动重连，这是有意为之：每次重连都要对方重新批准。
- 暂不支持持续双向同步、冲突合并，以及连接外部 Agent 主机（例如只有终端的 SSH 主机）。
- 已交付给对方的副本无法远程收回。

>每一步都看得见

正文保持连续阅读，思考与工具步骤按需展开。读了哪些文件、改了哪几行、跑了什么命令，都摆在会话里；做完把结果说清楚。

>危险操作先问你

「自动批准」下，常规操作直接执行，危险操作与项目外写入先确认。可以允许一次、在本会话允许，或者拒绝。

>成果就在会话旁边

改动、网页、终端以标签开在右栏。Agent 操作的网页直接显示在这里，随时可以接管。

>子 Agent 分头做事

给子任务指定模型，在后台并行处理；进度汇总回会话，运行中可以直接插话。

>长任务继续聊

接近你设定的上下文上限时自动压缩，留下摘要，原文快照可查回。

>手机上接着办

Android 客户端配对电脑后，可以看进度、回复、审批、切换模型。仍在测试。

>还有这些

模型
登录模型服务或填入 API Key，随时切换模型与思考档位。
技能与 MCP
按全局或当前项目配置。
本地快照
符合条件的项目在发送前保存快照，方便预览和回退。
预测下一句
回复结束后用灰字预测，Tab 填入。
插件
语音输入、桌宠、ComfyUI，按需安装。
数据在本机
聊天记录和设置都存在你自己的电脑上。

>开始使用

  1. 下载安装包并安装，之后在后台自动更新。
  2. 在 设置 → 模型 里登录，或填入 API Key。
  3. 新建会话，选好项目文件夹，说出要做的事。

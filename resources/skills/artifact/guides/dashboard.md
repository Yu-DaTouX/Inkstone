# 仪表盘 · 数据表 · 报告页

适用：用户要看数字、比较、趋势，例如「做个澳洲人均收入表」「看下这几年的销量」。

## 结构（自上而下）

1. **标题 + 一句结论**：直接说结果，例如「全国周收入中位数 2,083.70 澳元，ACT 最高」。
2. **首屏结论（三选一，不叠加）**：一句结论配一张主图；或一个主角数字；或不超过 4 个数字（卡片、表头行、图内标注都行），每个数字带单位和一行对比（同比、排名、占比）。
3. **主图表**：只放最能回答问题的一张；必要时加一张辅助图。
4. **明细表**：可排序；行多时加搜索框；数值列右对齐、等宽数字、千分位。
5. **来源与口径**：页脚写数据来源（机构名 + 表名或链接文字）、数据时间、单位和「近似值」说明。

## 图表（手写 SVG）

- **先选形式，最后上色**：
  - 单个数值：不画图，直接写成数字；
  - 单一比例：进度条或仪表；
  - 超过 7 个类目且都重要：用表格，不要靠更多颜色分开；
  - 系列超过 6 个：合并成「其他」，或画成小多图；
  - 比较类目：横向条形图，按数值排序；趋势：折线图，最多 4 条线；占比：堆叠条形图，饼图最多 5 份；分布：直方图。
- **颜色**：
  - 底色、表面、文字用风格牌的 `colors.bg` / `surface` / `ink`。
  - 系列色按风格牌 `colors.series` 的顺序分配；颜色跟随实体，不跟随排名——排序或筛选后同一实体颜色不变。
  - 要突出一项时用 `accent`，其余降到 `muted` 色；不要彩虹配色。
  - 状态色（好 / 警告 / 差）和强调色分开，并且配图标或文字，不能只靠颜色。
- **图形细节**：
  - 单一 y 轴，不做双轴。
  - 折线用直线段，不画平滑曲线。
  - 条形图条宽 ≤ 32px，相邻条之间留出间隙。
  - 网格线 1px，只留横向。
  - 数值标签用正文字色，不用系列色。
- 使用 `viewBox`，宽度 100%。坐标轴刻度取整（0、500、1000…）；条形图从 0 起，折线图可以不从 0 起，但要标注。
- 数值标签放在条末或点旁，放不下就只在悬停时显示（用 `<title>` 或页面内浮层）。

## 交互

- 指标切换用分段按钮，排序点表头，筛选用下拉或搜索。全部写在内存状态里。
- 悬停高亮同一项在图和表中的对应元素。
- 窄屏：数字横排时两列，表格外包一层横向滚动容器，图表高度固定。

## 数据

- 先查一手来源（统计局、央行、公司年报）；查不到就用你确知的数，标「约」和时间。
- 数据写成页面里的一个 `const DATA = [...]`，图和表都从它生成，避免两处数字不一致。

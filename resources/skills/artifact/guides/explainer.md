# 交互讲解 · 可视化教学

适用：「讲讲复利怎么算」「演示一下排序算法」「解释 TCP 三次握手」这类，要让人通过动手看懂一个概念。

## 结构

1. **一句话问题**：这页回答什么，例如「为什么复利后期增长得越来越快？」。
2. **可操作的主图**：一个 SVG 或 canvas 图，配 1–3 个控件（滑块、步进按钮、播放 / 暂停）。改控件后，图和数字立即更新。
3. **分步讲解**：3–6 步。每步一小段文字，并高亮图里对应的部分；用「上一步 / 下一步」切换，显示步数。
4. **小结**：三条要点，再加一个「试试看」：让用户调某个参数，观察指定现象。

## 原则

- 先给直觉，再给公式。公式用 HTML 和 `<sup>`、`<sub>` 写，不引用公式库。
- 每次只变化一个量。对比时左右并排，或者前后叠加半透明。
- 动画只用来展示过程（例如排序时的交换），可以暂停、可以单步；默认停在第一步，不要自动播放。
- 数字保留合适的精度，单位写清楚。
- 窄屏下控件放在图的下方，滑块要有足够的触控高度。

## 例子方向

- 算法：排序、二分查找、图搜索。用数组方块或节点图，每步标出比较或交换。
- 金融：复利、贷款月供。用曲线加表格，配本金、利率、年限三个滑块。
- 物理 / 数学：抛物线、概率模拟。模拟要有「重置」和「随机种子」。

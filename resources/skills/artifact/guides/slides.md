# 幻灯片 · 演示

适用：「做几页 PPT 讲一下 X」，但用户没有要求交付 .pptx 文件（要 .pptx 时看 office 技能）。

## 结构

- 页面是一组 16:9 的 `<section class="slide">`，每页结构同海报指南：`width: min(100%, 1100px); aspect-ratio: 16 / 9; container-type: inline-size`，内部全部用 `cqi`。
- 一次显示一页，带以下操作：
  - 底部：页码「3 / 8」、上一页 / 下一页按钮；
  - 键盘：← → 翻页，Home / End 跳到首页 / 末页；
  - 触屏：左右滑动翻页。
- 加一个「全部」按钮，切换成纵向排列所有页的概览，方便打印和截图。

## 每页

- **封面**：标题、副标题、日期 / 作者占位。
- **内容页**：一句结论做标题（不是「背景介绍」这种名词），下面最多 3 个要点，或一张图配一句说明。
- **数据页**：一张手写 SVG 图，加一句解读。
- **结尾**：总结三点，或下一步行动。

## 原则

- 一页只讲一件事，正文字号不小于 2.4cqi。
- 统一的页边距和标题位置。用一个强调色贯穿全篇。
- 翻页切换在 200ms 内完成，或者不做动画。

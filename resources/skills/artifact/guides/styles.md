# 点名风格速查（补充）

**只在用户点名的风格没有对应风格牌时使用**（先用 `yan artifact style --list` 查；水墨、国潮、孟菲斯等已有牌，优先用牌）。用户没指定风格时不要从这里挑，按 SKILL.md 抽风格牌。这里只补充中文语境常见风格的配色起点和母题：一种风格只取 2–3 个母题，把大胆用在一处。

| 风格 | 配色起点 | 字体与排版 | 母题 |
| --- | --- | --- | --- |
| 东方水墨 | 宣纸 #EFE9DD、浓墨 #1E1B18、印章红 #B5302A | 宋体 / 楷体竖排，大量留白 | 墨圈飞白、印章、山形淡墨 |
| 像素复古 | 天蓝 #8FBCF7、草绿 #5DA130、泥土 #8B5A2B、白 | 等宽字体，文字加 2px 硬描边 | 方块、阶梯边缘、像素云（`box-shadow` 拼像素） |
| 赛博霓虹 | 深紫黑 #0B0716、霓虹粉 #FF2E88、青 #19F0FF | 窄体大写，字间距加宽 | 发光描边（`text-shadow`）、扫描线、网格透视 |
| 国潮 | 中国红 #C8102E、金 #D4A84B、墨绿 #0F4D3A | 粗宋体标题配细线框 | 祥云、回纹、扇形、对称构图 |
| 孟菲斯 | 亮黄 #FFD23F、湖蓝 #3BCEAC、粉 #EE4266 | 圆体粗字，略倾斜 | 波浪线、圆点、三角、撞色块 |
| 酸性 Y2K | 银灰渐变、荧光绿 #C6FF00、紫 #7B2FFF | 变形宽体、描边字 | 金属渐变、星芒、液态形状 |
| 自然手作 | 燕麦 #E9DFCF、橄榄 #6B7A3A、陶土 #C0673E | 手写感衬线，柔和圆角 | 叶片、纸张纹理、手绘线 |

配色写成 CSS 变量：`--bg`、`--ink`、`--accent`、`--accent-2`。字体清单见 `SKILL.md` 里「官方设计技能在砚里的差异」。

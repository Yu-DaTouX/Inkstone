# 小游戏

适用：「做个贪吃蛇 / 2048 / 打砖块 / 记忆翻牌 / 打字练习」这类单页小游戏。

## 骨架

- **开始界面**：一张遮罩卡片，写游戏名、一句玩法和操作说明，加一个「开始」按钮。iframe 里要先点击一次才能收到键盘事件，所以必须先点开始。
- **游戏区**：`<canvas>` 或 DOM 网格。
  - canvas 按容器宽度设置像素尺寸（乘以 `devicePixelRatio`），窗口尺寸变化时重算。
  - 逻辑坐标与像素分开。
- **状态栏**：分数、最高分（只存内存）、关卡、暂停按钮。
- **结束界面**：显示得分，带「再来一局」按钮。

## 循环与输入

- 用 `requestAnimationFrame`，并按时间步长更新（`dt`）。帧率波动时速度不能变。
- 支持以下操作：
  - 键盘：方向键 + WASD；空格暂停，Enter 开始，R 重开；
  - 触屏：滑动或屏幕按钮，窄屏下显示方向键面板；
  - `keydown` 里对方向键调用 `preventDefault`，避免页面滚动。
- 页面失焦（`blur` / `visibilitychange`）时自动暂停。

## 手感

- 难度递增要平缓。前 10 秒不能让玩家死掉。
- 得分、碰撞、升级给出即时反馈：闪一下、数字弹跳、短暂震屏。动画控制在 150–300ms，并尊重 `prefers-reduced-motion`。
- 不能用 `localStorage`，最高分写成「本次最高」。

## 自检重点

- 预览截图只能看到开始界面，所以要额外确认：
  - 脚本没有报错；
  - 开始界面在窄屏完整显示；
  - 按钮可以点。
- 不要在加载时自动开始游戏。

# 网页原型 · 落地页 · 个人主页

适用：「做个咖啡店官网」「产品落地页」「我的个人主页」「App 首页原型」这类。

## 区块（按需选取，4–7 段）

1. **导航**：Logo 文字、3–5 个锚点链接、一个主按钮。窄屏下改成菜单按钮，展开后是页面内的抽屉。
2. **首屏**：一句价值主张（不超过 14 个字）、一句补充说明、主按钮 + 次按钮，右侧或下方放一个主视觉（CSS / SVG 画的产品示意、插画或抽象图形）。
3. **卖点**：3 或 4 个，每个是图标（内联 SVG）+ 短标题 + 一句话。
4. **展示**：产品截图示意、菜单、作品集网格或价格表。价格表三档，中间一档推荐。
5. **证据**：数字（用户数、评分）或 2–3 条评价。用明显的占位，例如「用户 A」。
6. **常见问题**：用 `<details>` 折叠。
7. **页脚**：联系方式占位、版权。

## 原则

- 先确定一个品牌色和一套字号阶梯（例如 14 / 16 / 20 / 28 / 44），全页只用这些值。
- 区块之间留足间距（80–120px），区块内部对齐同一网格。最大内容宽度 1120px。
- 链接和按钮在页面内滚动定位，不跳转外部。表单只在页面内显示「已提交（演示）」。
- 首屏要在 1280×800 的预览里完整可见，这也是对话里缩略图看到的部分。
- 文案贴合用户说的行业，不要通用废话。

# 海报 · 邀请函 · 名片 · 证书 · 封面

适用：一张固定画幅的平面设计稿。用户要的是「能直接拿去用的一张图」，不是网页。

## 画幅

| 类型 | 比例 | 说明 |
| --- | --- | --- |
| 竖版海报 | 420 / 594（A 系列） | 默认选这个 |
| 社交方图 | 1 / 1 | 朋友圈、小红书封面 |
| 横幅 / 封面 | 16 / 9 | 视频封面、公众号头图 |
| 名片 | 90 / 54 | 正反面并排两张 |
| 邀请函 | 5 / 7 | 竖版，留足留白 |

结构固定为：

```html
<main class="stage"><article class="canvas">…</article><p class="note">占位说明</p></main>
```

- `.canvas { width: min(100%, 720px); aspect-ratio: 420 / 594; container-type: inline-size; position: relative; overflow: hidden; }`
- 画幅宽度只跟随容器宽度。**不要用 `vh` / `dvh` 算宽度**：缩略图和窄屏视口很矮，按高度算会把整张图压成一条。
- 画幅内所有字号、间距、位置都用 `cqi`（画幅宽度的百分之一），这样任何尺寸下整张等比缩放、不重排。
- `.stage` 用普通块级布局加 `margin-inline: auto` 居中，不要用 `display:flex/grid` 加居中对齐包住 `.canvas`（`container-type` 在收缩布局里会把宽度算成 0）。

## 版式

视觉方向（配色、字体、构图、主角是什么）按 `official/frontend-design` 或 `official/canvas-design` 定，这里只列海报在砚里的技术要点：

1. **一个主角**：画面只让一个元素最抢眼，其余让路。
2. **字号用 `cqi`**：最小的文字不低于 2cqi，保证缩略图里还认得出层级。
3. **印刷类设计在深色模式下只换页面底色**，画幅本身不变色。
4. **图形用 CSS / 内联 SVG 画**：几何、笔触、纹理（`repeating-linear-gradient`、SVG `feTurbulence` 颗粒）。不要用外部图片和图标字体。

## 文案

用户没给内容时，自己定一个具体主题（例如「城市回声 · 声音艺术展」），日期、地点、主办写成一眼能认出的占位，并在画幅外用 `.note` 写一行「以上为占位文案」。

## 自检重点

- 窄屏截图里整张等比缩小，文字没换行错位、没被裁掉。
- 竖排、绝对定位的元素互不压叠。
- 颗粒、纹理层铺满整个画幅（`inset: 0; width: 100%; height: 100%`）。

# 缺能力时怎么办

砚负责能力目录、联网检索、接入计划与安全检查（`yan capabilities …`）。这个技能告诉你按什么顺序找，以及常见需求通常从哪里补。

原则：**装不装由用户决定**。接入时砚会弹出限时批准面板，你不需要也不能替用户批准；认不出需求时不要猜包名。命令参数和返回状态见 `yan capabilities --help`。

## 1. 顺序

1. **先查已有的**：`yan capabilities search --query-text "<要做的事>"`，也覆盖已登记 MCP 服务的工具。查到就直接用，并告诉用户「你已经有这个能力」。
2. **本地没有再联网找**：`yan capabilities discover --query-text "<英文短词>"`；用户点名某个仓库时加 `--repo owner/name`。
3. **选一个最合适的接入**：`yan capabilities acquire --candidate <候选ID>`，等用户在面板上选；装好后马上读返回的 `skillFile` 继续原任务，被跳过就不要再请求同一个，按用户的话或不装东西的办法继续。被拦下（`blocked` / `failed`）时说明原因，换候选或走退路，不要绕过审查。
4. 都不行时说明缺什么，并给出不装东西的退路。

一次任务最多申请接入一两个技能，不要为了「可能有用」去装。MCP 服务的接入不走 acquire：需要新服务时告诉用户在设置 → 能力 → MCP 里管理（pi 原生，也可用 `/mcp`）。

## 2. 常见缺口

| 需求 | 通常缺什么 | 从哪里补 | 不装东西的退路 |
| --- | --- | --- | --- |
| 从 PDF / 文档里取表格和结构 | 结构化解析 | 技能包；Office 文件先看 `office` 技能 | `yan office read` 或按纯文本读，表格会散成行 |
| 统计表格数据、画图 | 数据统计与画图 | 技能包，或本机 Python | 读成文本后计算；图交给 `yan image generate` |
| 打开网页读正文 | 不缺，砚自带 | `yan browser navigate --url <地址>`，再 `yan browser observe` | — |
| 录音转写 / 朗读 | 语音能力 | 电脑端输入框有本地转写（设置 → 能力 → 本机工具 → 本地转写）；朗读需要 MCP 服务 | 先用其他工具转成文本 |
| 看图片里写了什么 | 取决于当前模型是否支持看图 | 换支持视觉的模型 | 先 OCR 成文本 |
| 连数据库查数 | 数据库客户端 | 数据库 MCP 服务（连接串与凭证由用户配置） | 用本机命令行导出 CSV 再读 |
| 按语义搜整个代码库 | 索引式检索 | 技能包 | 先 grep 定位，再精读文件 |
| 把结果发到邮件 / 群 / 工单 | 对外发送通道（砚不内置） | 提供发送能力的 MCP 服务；每次发送前由用户确认 | 写成文件，由用户自己发出去 |
| 长视频 / 长音频做笔记 | 转写能力 | MCP 服务或本机工具 | 先拿到字幕或文稿，再分段处理（可用子代理，见 `subagent` 技能） |

## 3. 接入前后

- 申请接入前用一句话说明为什么需要它，面板会列出来源和内容。
- 接入后先用一个小任务验证能用，再继续原来的任务。

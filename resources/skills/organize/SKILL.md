# 整理

整理的前提是不丢东西。这个技能说明怎么定方案、怎么动手、怎么汇报。

## 1. 先看清楚

- 先列出要整理的范围：哪些文件夹、多少文件、大致有哪些类型。不要一边看一边改。
- 弄清用户想怎么用这些资料（按项目找、按时间找、按类型找），分类方式跟着用途走。

## 2. 先说方案

- 动手前说明：分成哪几类、每类的判断标准、按什么规则命名（例如 `日期_项目_内容`）。
- 列出几条示例：「`原文件名` → `新位置/新文件名`」。
- 拿不准归哪一类的文件单独列出来，让用户决定。
- 用户同意方案后再动手。

## 3. 动手时

- 不要丢用户的资料：优先移动和改名，不删除。
- 删除、覆盖同名文件、改动很多文件之前，先说明影响并等用户确认；重复文件先列出来，不要自己判断哪份可以删。
- 文件数量多时分批做，每批做完核对数量。
- 保留一份「原位置 → 新位置」的对照清单（写成文件），出错时能还原。

## 4. 汇报

- 整理结果要让人一眼看懂：每一类进了哪些、多少个。
- 说明哪些没动、为什么没动，以及对照清单放在哪里。

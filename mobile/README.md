# 砚 · 手机端（Android）

[项目主页](../README.md) · [手机接入说明](../docs/MOBILE_ACCESS.md) · [设计规范](../docs/DESIGN_SYSTEM.md) · [技术路线](../docs/TECH_STACK_OPTIONS.md)

手机端让你在离开电脑时继续参与电脑上的任务：查看会话与运行状态、回复等你回答的问题、发送文字或语音转写文字、中止运行、查看成果文件。**任务始终在电脑上的砚里执行**；手机断线不会中止电脑上的任务，电脑上的砚关闭后手机无法访问。

技术选择：React Native + TypeScript。与桌面端同一种语言，电脑与手机共用 [`src/shared/remote-protocol.ts`](../src/shared/remote-protocol.ts) 里的协议类型（手机端只做 `import type`，打包时擦除）。

## 连接方式

1. 电脑上打开 **设置 · 手机接入**，打开「允许手机接入」。默认只在 Tailscale 网络里监听；也可以选「仅本机」再用 SSH 端口转发，或指定一个局域网 IP。
2. 点「生成配对码」，用手机扫描二维码自动填入电脑地址与 6 位配对码，或手动输入。配对码 5 分钟有效、只能用一次，输错 5 次作废。
3. 配对得到的设备令牌保存在系统钥匙串里。电脑上随时可以撤销某台手机，撤销后它立即断开。

删除、授权、付费这类**敏感确认**在手机上只能拒绝，同意必须在电脑上操作。

会话和普通问题的输入框有「语音转文字」按钮。录音界面保留在输入栏内，通过手机已安装的识别服务转写，不再打开外部识别弹窗；首次使用申请麦克风权限。小波形随实际收音变化，方形按钮结束录音并等待文字，取消或返回键放弃输入，切到后台会取消录音。识别服务可能联网；返回的文字先填入输入框，核对后单独发送。

Samsung Fold6 已验证服务启动、输入栏波形、取消和无语音错误恢复；小米设备当前唯一的第三方识别服务缺少麦克风权限，保留明确提示与键盘输入。两台设备的真实语句转写准确率尚未验证。

宽屏显示项目列表与详情双栏，详情顶部的侧栏按钮可收起或展开列表。收起不重置会话、阅读位置和草稿。通过 AndroidX WindowManager 获取铰链几何；Fold6 内外屏与键盘避让已有实机检查，遮挡铰链和桌面姿态仍需对应设备状态验证。

## 可靠性约定

- 事件流带序号：断线重连时补发期间的事件；电脑重启过或断线太久时整体刷新。
- 发送消息、回答问题、中止运行都带幂等键：弱网下重试不会让电脑执行两次。
- 成果只按 id 从电脑读取真实文件，远程接口不暴露电脑上的路径。
- 会话先读最近 60 条，向上按需读取更早历史；正文使用虚拟列表与组件复用。当前配对连接的内存缓存最多 6 个会话、每个 120 条、单个约 1 MiB、总计约 2 MiB 序列化内容，退出应用即清空，不落盘。
- 新版桌面支持按消息 ID 分页；兼容旧桌面时逐步扩大读取范围，最多 500 条，更早记录提示在电脑查看。桌面升级并重新启动后可继续使用游标分页。
- 开启手机通知后，常驻通知显示真实运行任务标题与运行/待回答状态，空闲显示已连接，断线显示重新连接。任务标题在锁屏公共版本隐藏；新问题仍单独提醒一次。

## 构建

目录里包含应用源码（`src/`）与 Android 原生工程（`android/`）。首次构建前需要：

- Node 20.19.4 或更高、JDK 17（本机 JDK 21 也已构建通过）；
- Android SDK Platform 36、Build Tools 36.0.0、NDK 27.1.12297006，并配置 `ANDROID_HOME`；
- 在 `mobile/` 运行 `npm install`、`npm run typecheck`；连接设备后可运行 `npm run android`，或运行 `npm run build:apk` 构建本机调试 APK。

`npm run build:apk`（`scripts/build-apk.mjs`，直接调用 Gradle，并把 APK 与 SHA-256 整理到仓库 `release/apk-<版本>-<提交>/`）会把 JavaScript 一起打入 `android/app/build/outputs/apk/release/app-release.apk`，安装后不需要 Metro 开发服务器。存在 `~/.inkstone-signing/keystore.properties` 时用正式签名密钥签名（密钥在仓库之外，见 [Windows 打包与数据](../docs/dev/RELEASING.md#android-手机端)），否则退回调试密钥，只供本机安装验证。桌面端构建不会编译这个目录。依赖版本以 `package-lock.json` 为准；原生工程由 React Native Community CLI 20.0.0 的 0.81.0 模板生成。

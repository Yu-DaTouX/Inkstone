02 六条规则

  1. 16 网格，12 活动区：四周留 2px，与 12/14/16 三档尺寸对齐
  2. 描边恒定 {{sw}}px：vector-effect: non-scaling-stroke，三档一样粗
  3. 方头 · 斜接：取自标志的 >_；不用圆头圆角
  4. 开口角：文件、目录、终端、外链等容器右上角留缺口
  5. 直线与整圆：0° / 45° / 90° 为主，不画插画式隐喻
  6. 进行中不用图标：用方点阵；状态点、勾选框由 CSS 画
